What this website does

This website helps students reach the correct study area quickly. Students can open a department, choose the semester, confirm the subject code and use the resources available on that subject card.

Ask POLY AI can guide students through the website, search the current website index and answer general diploma study questions. Saved-chat availability depends on browser storage support.

REV 2026

Current curriculum directory

Revision 2026 is the current curriculum area. It contains 38 programme pages with semester-wise subject records and revision-specific resources.

REV 2021

Legacy curriculum directory

Revision 2021 remains available for batches still following that curriculum. Its subjects and resources must never be mixed with Revision 2026.

ASK POLY

AI website guide

Ask POLY AI helps with subject finding, missing notes, mock-exam guidance, tools, website help and normal diploma study doubts.

TOOLS

Useful student tools

The Tools area contains calculators, converters and helper utilities for study, exam preparation and engineering-related quick work.

Important student note

POLY PMNA is a study-support and revision-helper platform. It is not a replacement for official syllabus documents, institution instructions, SITTTR notices, approved textbooks or teacher guidance.

  • Always verify final syllabus, marks and exam pattern from official sources.
  • If a link, code or material is wrong, use the Help page and include the page URL, revision, subject code and screenshot.
  • Ask POLY AI can help guide and explain, but official academic instructions must be followed first.
