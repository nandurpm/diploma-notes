What this website does

This website helps students reach the correct study area quickly. Instead of searching many pages, students can open a department, choose the semester, check the subject code and use the available resources from one organized subject card.

Ask POLY AI is now included as a separate main section. It can guide students through the website, remember browser-side chat history, answer study questions through the configured AI backend, and use local website knowledge for faster answers where possible.

REV 2021

Department-wise subject access

Revision 2021 pages are arranged department-wise and semester-wise. Subject cards guide students to syllabus, sample question paper links and uploaded lessons or notes where available.

ASK POLY

AI website guide

Ask POLY AI helps with subject finding, missing notes, mock exam guidance, tools, website help and normal diploma study doubts. Chats are saved in the browser using IndexedDB.

EXAMS

Mock exam practice

The Mock Exams section supports daily practice, official-pattern mock exams, saved attempts and result feedback so students can identify weak areas before exams.

TOOLS

Useful student tools

The Tools area contains calculators, converters and helper utilities for study, exam preparation and engineering-related quick work.

START

LEARN

Read available lessons, check notes, confirm syllabus links and use sample question paper links from the subject cards.

PRACTISE

After studying, use Mock Exams and question-paper resources to check understanding and improve revision priority.

Important student note

POLY PMNA is a study-support and revision-helper platform. It is not a replacement for official syllabus documents, institution instructions, SITTTR notices, approved textbooks or teacher guidance.

  • Always verify final syllabus, marks and exam pattern from official sources.
  • If a link, code or material is wrong, use the Help page and include the page URL, subject code and screenshot.
  • Ask POLY AI can help guide and explain, but official academic instructions must be followed first.
