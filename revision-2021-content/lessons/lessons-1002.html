Module 1

Matrices and Determinants

Matrices provide a compact language for simultaneous relationships and engineering data. This module builds the algebra needed to solve two- and three-unknown systems.

11 L + 4 Tofficial hours
CO1mapped CO

Learning goals

  • Classify matrices and identify order.
  • Perform transpose and matrix operations.
  • Evaluate determinants and use Cramer’s rule.
  • Find minors, cofactors, adjoint and inverse.

Key facts

  • Order is written rows × columns.
  • Matrix multiplication is row-by-column.
  • An inverse exists only when the determinant is non-zero.
  • Cramer’s rule replaces columns with constants.
Engineering relevance: Matrices model simultaneous equations in circuits, mechanics, surveying, process calculations and data tables.
Basic concept of a matrix and special types of matrices

A matrix is a rectangular arrangement of quantities written in rows and columns. Its order is m × n when it has m rows and n columns. Recognise row, column, square, diagonal, triangular, identity and zero matrices before performing operations.

A = [aᵢⱼ]ₘ×ₙ

The position of an entry is identified by its row and column indices. A square matrix has equal numbers of rows and columns; an identity matrix has ones on the principal diagonal and zeros elsewhere.

Given: A = [[2, 0], [0, 5]]
Required: Classify the matrix
Calculation: It has 2 rows and 2 columns; the off-diagonal entries are zero.
Answer: A is a 2 × 2 diagonal square matrix.
Malayalam support: Matrix എന്നത് rows and columns ആയി ക്രമീകരിച്ച സംഖ്യകളുടെ rectangular arrangement ആണ്. ആദ്യം orderയും matrix typeഉം തിരിച്ചറിയുക.
Common mistake: Do not confuse a diagonal matrix with any square matrix. Every diagonal matrix is square, but not every square matrix is diagonal.
Transpose of a matrix

The transpose changes rows into columns. If A = [aᵢⱼ], then Aᵀ = [aⱼᵢ]. The order m × n becomes n × m.

A = [[1, 2, 3], [4, 5, 6]] ⇒ Aᵀ = [[1, 4], [2, 5], [3, 6]]

Important properties include (Aᵀ)ᵀ = A and (A + B)ᵀ = Aᵀ + Bᵀ. Carefully copy the main diagonal and reflect entries across it.

Malayalam support: Transpose ചെയ്യുമ്പോൾ row column ആയും column row ആയും മാറുന്നു. Main diagonal മാറ്റമില്ലാതെ തുടരും.
Check: Count the order before and after transposition.
Algebra of matrices: scalar multiplication, equality, addition, subtraction and multiplication

Equality requires equal order and equal corresponding entries. Addition and subtraction are possible only for matrices of the same order. Scalar multiplication multiplies every entry by the scalar.

(AB)ᵢⱼ = Σ aᵢₖbₖⱼ; AB is defined when columns of A = rows of B.

Matrix multiplication is generally not commutative: AB may exist while BA does not, or AB ≠ BA. Use row-by-column multiplication and retain the correct order.

Given: A = [[1,2],[3,4]], B = [[2,0],[1,5]]
Required: Find AB
Calculation: AB = [[1×2+2×1, 1×0+2×5], [3×2+4×1, 3×0+4×5]] = [[4,10],[10,20]].
Answer: AB = [[4,10],[10,20]].
Malayalam support: Matrix multiplication row-by-column ആണ്. ABയും BAയും ഒരേ result ആവണമെന്നില്ല.
Common mistake: Adding matrices of different orders or multiplying corresponding entries instead of using row-by-column multiplication.
Determinants and Cramer’s rule for two and three unknowns

The determinant is a scalar associated with a square matrix. For a second-order matrix, det(A)=ad−bc. For a third-order determinant, expand by a row or column using signed cofactors.

For ax+by=p, cx+dy=q: Δ = ad−bc; Δₓ = pd−bq; Δᵧ = aq−pc; x=Δₓ/Δ, y=Δᵧ/Δ

Cramer’s rule replaces one column of the coefficient determinant with the constants. It is valid when the coefficient determinant is non-zero. Apply the same idea to three unknowns by forming Δ, Δₓ, Δᵧ and Δ_z.

Given: 2x + y = 5; x − y = 1
Required: Find x and y
Calculation: Δ = (2)(−1)−(1)(1)=−3; Δₓ=(5)(−1)−(1)(1)=−6; Δᵧ=(2)(1)−(5)(1)=−3.
Answer: x=2, y=1.
Malayalam support: Cramer’s rule ഉപയോഗിക്കുമ്പോൾ ആദ്യം coefficient determinant Δ പൂജ്യമല്ലെന്ന് പരിശോധിക്കുക. Column replacement ശ്രദ്ധിക്കുക.

Engineering use: simultaneous equations model unknown currents, forces, flow rates or component values.
Minors, cofactors, adjoint and inverse of a 2 × 2 matrix

The minor Mᵢⱼ is the determinant obtained after deleting row i and column j. The cofactor is Cᵢⱼ = (−1)ⁱ⁺ʲMᵢⱼ. The adjoint is the transpose of the cofactor matrix.

A⁻¹ = adj(A)/|A|, provided |A| ≠ 0; for [[a,b],[c,d]], A⁻¹ = 1/(ad−bc) [[d,−b],[−c,a]]

To solve AX=B using an inverse, calculate X=A⁻¹B. If |A|=0, the inverse does not exist.

Given: A = [[2,1],[1,1]]
Required: Find A⁻¹
Calculation: |A|=2(1)−1(1)=1; A⁻¹=[[1,−1],[−1,2]].
Answer: A⁻¹=[[1,−1],[−1,2]].
Malayalam support: Minor, cofactor, adjoint എന്നിവയുടെ ക്രമം തെറ്റിക്കരുത്: minors → cofactors → cofactor matrix transpose → adjoint.

Problems and engineering applications

Problems consolidate all matrix operations. A safe solution sequence is: write the data as matrices, check dimensions, select determinant/Cramer/inverse method, calculate neatly, and verify by substitution.

Quadratic-check calculator

This supports algebra practice used alongside matrix modelling.

Enter coefficients and calculate.
Malayalam support: പ്രശ്നങ്ങളിൽ final answer substitute ചെയ്ത് verify ചെയ്യുന്നത് exam-ലും engineering practice-ലും വളരെ പ്രധാനമാണ്.
Professional habit: Keep units and variable definitions visible when the matrix represents physical quantities.

Module summary

Represent the problem first; then choose the operation that matches the matrix structure.

Module 2

Trigonometry

Trigonometry links angles to ratios and is used to analyse direction, slope, periodic behaviour and geometric relationships.

11 L + 4 Tofficial hours
CO2mapped CO

Learning goals

  • Classify and convert angles.
  • Use standard trigonometric ratios.
  • Apply Pythagorean identities and ASTC.
  • Solve compound-angle problems.

Key facts

  • Use radians in calculus limits.
  • ASTC determines signs by quadrant.
  • Compound-angle formulae must preserve paired signs.
  • Check answers with an identity or approximate value.
Engineering relevance: Surveying, force resolution, AC signals, vibration and geometry rely on trigonometric relationships.
Angles

Classify acute, obtuse, right, straight, reflex, complete, positive and negative angles. The direction convention matters when an angle is measured from a reference axis.

1 revolution = 360° = 2π radians; 180° = π radians
Given: θ = 150°
Required: Convert to radians
Calculation: θ(rad)=150×π/180=5π/6.
Answer: θ=5π/6 rad.
Malayalam support: Angle type ആദ്യം തിരിച്ചറിയുക. Degree–radian conversion-ൽ π/180 factor ഉപയോഗിക്കുക.
Common mistake: Mixing degrees and radians in a trigonometric limit or formula.
Trigonometric ratios of acute and standard angles

For a right triangle, sin θ = opposite/hypotenuse, cos θ = adjacent/hypotenuse and tan θ = opposite/adjacent. Memorise standard values at 0°, 30°, 45°, 60° and 90° and derive reciprocal ratios when needed.

Check: sin²θ + cos²θ = 1 for every angle where the ratios are defined.
Pythagorean relations, ratios of any angle, ASTC rule and reduction formula

Use sin²θ+cos²θ=1, 1+tan²θ=sec²θ and 1+cot²θ=cosec²θ. The ASTC rule identifies positive ratios in quadrants I–IV: All, Sine, Tangent, Cosine. Reduction formulae express a ratio of an angle outside the first quadrant using a related acute angle and the correct sign.

sin(180°−θ)=sin θ; cos(180°−θ)=−cos θ; tan(180°−θ)=−tan θ
Given: sin θ = 3/5, θ acute
Required: Find cos θ and tan θ
Calculation: cos θ=√(1−9/25)=4/5; tan θ=(3/5)/(4/5)=3/4.
Answer: cos θ=4/5, tan θ=3/4.
Malayalam support: ASTC വഴി sign കണ്ടെത്തുക; reduction formulaയിൽ quadrant sign മറക്കരുത്.
Common mistake: Taking the positive square root without checking the quadrant.
Compound angles: A+B and A−B

Compound-angle identities expand the ratio of a sum or difference of two angles. Apply them only after identifying the signs and known ratios.

sin(A±B)=sinA cosB ± cosA sinB
cos(A±B)=cosA cosB ∓ sinA sinB
tan(A±B)=(tanA±tanB)/(1∓tanA tanB)
Given: A=45°, B=30°
Required: Find sin(A+B)
Calculation: sin75° = (1/√2)(√3/2)+(1/√2)(1/2)=(√6+√2)/4.
Answer: sin75°=(√6+√2)/4.
Malayalam support: A+B, A−B formulaകളിൽ plus/minus pairing ശ്രദ്ധിക്കുക. tan denominator zero ആണോ എന്നും പരിശോധിക്കുക.

Problems and engineering applications

Practise finding an unknown ratio, simplifying identities, evaluating compound angles and converting between forms. Trigonometry appears in surveying, mechanics, AC waveform analysis, vibration and structural geometry.

  1. Write the relevant identity before substituting values.
  2. Use a right triangle or identity to find missing ratios.
  3. Apply ASTC to determine signs.
  4. Check the answer using an approximate calculator value when permitted.
Malayalam support: Engineering application-ൽ angle convention, unit, sign എന്നിവ കൃത്യമായി രേഖപ്പെടുത്തുക.

Module summary

A correct diagram and sign analysis often prevent more errors than additional algebra.

Module 3

Coordinate Geometry

Coordinate geometry translates lines and circles into equations that can be analysed, compared and used in design.

11 L + 4 Tofficial hours
CO3mapped CO

Learning goals

  • Find slope and line equations.
  • Calculate the angle between lines.
  • Construct parallel and perpendicular lines.
  • Find circle centre and radius.

Key facts

  • Slope is change in y divided by change in x.
  • Parallel lines have equal slopes.
  • Perpendicular slopes multiply to −1.
  • Circle equations encode centre and radius.
Engineering relevance: Layouts, geometric design, CAD coordinates, surveying and path interpretation use coordinate equations.
Straight lines: slope and slope–point form

The slope m measures change in y per unit change in x. For two points (x₁,y₁),(x₂,y₂), m=(y₂−y₁)/(x₂−x₁). The slope–point form is y−y₁=m(x−x₁).

Slope-point form: y−y₁=m(x−x₁)
Given: Point (2,3), slope m=4
Required: Find the line equation
Calculation: y−3=4(x−2) ⇒ y=4x−5.
Answer: The equation is y=4x−5.
Malayalam support: Slope എന്നത് line-ന്റെ inclination/steepness ആണ്. Given point equation-ൽ നേരിട്ട് substitute ചെയ്യുക.

Angle between two lines

If two lines have slopes m₁ and m₂, the acute angle θ between them is determined by tanθ=|(m₂−m₁)/(1+m₁m₂)|, provided the denominator is non-zero.

tan θ = (m₂−m₁)/(1+m₁m₂)
Given: m₁=1, m₂=3
Required: Find the acute angle
Calculation: tanθ=(3−1)/(1+3)=1/2; θ=tan⁻¹(1/2)≈26.565°.
Answer: θ≈26.565°.
Malayalam support: Angle between lines-ൽ absolute value ഉപയോഗിച്ച് acute angle എടുക്കാം; slope undefined ആണെങ്കിൽ geometric method പരിഗണിക്കുക.

Parallel and perpendicular lines

Non-vertical parallel lines have equal slopes. Perpendicular lines satisfy m₁m₂=−1. Use the point–slope form to write the required line through a specified point.

Parallel: m₂=m₁; Perpendicular: m₂=−1/m₁
Given: Given y=2x+1 and point (3,4)
Required: Find a perpendicular line
Calculation: m₂=−1/2; y−4=−(1/2)(x−3).
Answer: y=−x/2+11/2.
Malayalam support: Parallel line-ന് same slope; perpendicular line-ന് negative reciprocal slope ഉപയോഗിക്കുക.

Circles: equation, centre and radius

A circle with centre (h,k) and radius r has equation (x−h)²+(y−k)²=r². The general equation is x²+y²+2gx+2fy+c=0, with centre (−g,−f) and radius √(g²+f²−c).

Given: x²+y²−6x+4y−12=0
Required: Find centre and radius
Calculation: 2g=−6 ⇒ g=−3; 2f=4 ⇒ f=2; centre=(3,−2); r=√(9+4+12)=5.
Answer: Centre (3,−2), radius 5.
Malayalam support: General equation-ൽ x coefficient-ന്റെ പകുതി g, y coefficient-ന്റെ പകുതി f തിരിച്ചറിയുക; signs ശ്രദ്ധിക്കുക.

Coordinate-geometry problems and applications

Coordinate geometry converts geometric conditions into algebraic equations. Typical engineering uses include locating points, fitting simple paths, interpreting layouts and defining geometric features in CAD.

  1. Draw a quick coordinate sketch.
  2. Choose the correct standard form.
  3. Substitute known data with signs.
  4. Verify by checking the centre, radius or slope against the geometry.

Module summary

Sketch the geometry before manipulating the equation.

Module 4

Differential Calculus

Differential calculus introduces limits and derivatives as tools for describing change and local behaviour.

12 L + 3 Tofficial hours
CO4mapped CO

Learning goals

  • Evaluate limits by substitution and factorisation.
  • Use standard limits.
  • Recall standard derivatives.
  • Apply product and quotient rules and find second derivatives.

Key facts

  • Radian measure is required for sinx/x.
  • 0/0 is a form requiring further algebra, not an automatic answer.
  • Product and quotient rules preserve structure.
  • Second derivatives describe change of slope.
Engineering relevance: Rates, optimisation, motion, response curves and error analysis depend on derivatives.
Concept of limit; substitution and factorisation

A limit describes the value approached by a function as x approaches a point. Direct substitution works when the function is defined and continuous at the point. If an indeterminate 0/0 form appears, factorise and cancel the common factor before substituting.

Given: lim(x→2) (x²−4)/(x−2)
Required: Evaluate the limit
Calculation: Factorise: (x−2)(x+2)/(x−2)=x+2; substitute x=2.
Answer: Limit = 4.
Malayalam support: Limit എന്നത് exact point value മാത്രം അല്ല; x point-നെ സമീപിക്കുമ്പോൾ function സമീപിക്കുന്ന value ആണ്.

Limits of (xⁿ−aⁿ)/(x−a) and sin x/x

Use algebraic factorisation for powers and the standard radian result lim(x→0) sinx/x=1. In related expressions, rewrite the function to expose the standard form.

lim(x→a)(xⁿ−aⁿ)/(x−a)=naⁿ⁻¹; lim(x→0) sinx/x=1 (x in radians)
Given: lim(x→0) sin(5x)/(5x)
Required: Evaluate the limit
Calculation: Let u=5x; as x→0, u→0. The expression is sin u/u.
Answer: Limit = 1.
Malayalam support: sin x/x standard limit-ൽ x radians ആയിരിക്കണം; degree ഉപയോഗിച്ചാൽ result മാറും.

Basic differentiation and standard results

Differentiation gives the instantaneous rate of change. Recall derivatives of a constant, xⁿ, eˣ, log x, sin x, cos x, tan x, cosec x, sec x and cot x.

d(k)/dx=0; d(xⁿ)/dx=nxⁿ⁻¹; d(eˣ)/dx=eˣ; d(log x)/dx=1/x; d(sin x)/dx=cos x; d(cos x)/dx=−sin x
Given: y=3x⁴−2x²+7
Required: Find dy/dx
Calculation: dy/dx=12x³−4x.
Answer: dy/dx=12x³−4x.
Malayalam support: Differentiation rate of change കണ്ടെത്തുന്നു. Constant term derivative zero ആണ്.

Rules of differentiation and second derivatives

Use linearity, product and quotient rules. The second derivative is the derivative of the first derivative and is useful for curvature and acceleration-type interpretations.

(uv)′=uv′+vu′; (u/v)′=(vu′−uv′)/v²; y″=d²y/dx²
Given: y=x² sin x
Required: Find y′
Calculation: y′=x²cosx+2x sinx.
Answer: y′=x²cosx+2x sinx.

Differentiate again carefully: y″=2x cosx−x² sinx+2 sinx+2x cosx.

Malayalam support: Product rule-ൽ first function × second derivative അല്ല; first × derivative of second + second × derivative of first ആണ്.

Problems and engineering applications

Limits and derivatives support velocity, slope, optimisation, error estimation, growth models and response curves. Present each solution as expression, rule, substitution and final value.

  1. Identify the form and choose substitution/factorisation or a standard limit.
  2. State the derivative rule before applying it.
  3. Simplify before evaluating.
  4. Check domain restrictions such as x≠0 or denominator ≠0.

Module summary

Name the rule, apply it carefully, simplify, then interpret the result.
