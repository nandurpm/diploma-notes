# POLY PMNA Windows portable app

This folder contains the Windows desktop wrapper for the live POLY PMNA website:

`https://polypmna.dpdns.org/`

The app is an Electron portable executable. It keeps its browser data beside the executable in `POLY PMNA Data`, so it does not require an installer or administrator access.

## Local development

```bash
cd windows-app
npm install
npm start
```

## Signed GitHub release

The workflow at `.github/workflows/build-windows-app.yml` creates a short-lived CI code-signing certificate, builds an x64 portable `.exe`, verifies its Authenticode signature, and publishes it to a GitHub Release. No certificate secret is required.

Because the certificate is self-signed and generated by CI, Windows may show an **untrusted publisher** warning. The file is still cryptographically signed. A commercial Authenticode certificate can be added later by replacing the certificate-generation step.

The workflow creates releases named `windows-v<version>`; bump `windows-app/package.json` before creating another release.
