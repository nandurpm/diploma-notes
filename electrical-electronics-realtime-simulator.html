Circuit Simulator Help
Getting Started:
1. Drag components from the left sidebar onto the canvas
2. Click on component terminals to connect wires
3. Double-click components to edit their properties
4. Click Run to start the simulation

Circuit Building:
• Drag components to place them
• Right-click for context menu (rotate, delete, duplicate)
• Use Snap-to-Grid for alignment
• Zoom in/out with mouse wheel

Simulation:
• Run: Start the circuit simulation
• Pause: Freeze the simulation
• Reset: Clear all readings and restart
• Speed: Adjust simulation speed (0.5x - 2x)

Fault Simulation:
• Click Fault button to inject faults
• Watch how components respond to errors
• Learn about protection mechanisms

Educational Mode:
• Select any component to see its properties
• View working principles and formulas
• Check measurement instruments for real-time data

Save/Load:
• Save circuits to browser storage
• Load previously saved circuits
• Export circuits as images
