# Notes (Revision 2021)

Downloadable study notes for KSBTE Revision 2021 diploma courses.

## Structure

Notes are stored as PDF files named `notes-[COURSE_CODE].pdf` where the course code is a 4-digit number (e.g., `notes-1001.pdf`).

## Access

Notes are accessible from the subject cards on the Revision 2021 department pages. The `revision-2026-browser.js` and Revision 2021 equivalents generate download links pointing to these files.

## Relationship to Lessons

- `lessons/` contains the HTML lesson pages for the same courses
- `notes/` contains the downloadable PDF versions
- Both are linked from the subject cards on department pages

## File Format

All notes are PDF files optimised for printing and offline study. They include the POLY PMNA watermark.
