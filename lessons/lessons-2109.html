Module 1: Word Processing (CO1)

Duration: 16 Hours

M1.01: MS Word Orientation & Basics

Microsoft Word is a graphical word processing program that users can type with. Its purpose is to allow users to type and save documents.

  • Accessing: Start > All Programs > Microsoft Office > MS Word.
  • Toolbars: Quick Access Toolbar, Ribbon (Home, Insert, Page Layout, etc.).
  • Format Painter: Used to copy formatting from one item to another. Select text with formatting -> Click Format Painter -> Select target text.
  • Rulers: Horizontal and Vertical rulers help in aligning text, setting tabs, and margins.
Malayalam support: MS Word ഒരു ഡോക്യുമെന്റ് തയ്യാറാക്കാൻ ഉപയോഗിക്കുന്ന സോഫ്റ്റ്‌വെയറാണ്. ഇതിലെ Format Painter ഉപയോഗിച്ച് ഒരു ഭാഗത്തെ ഫോർമാറ്റിംഗ് മറ്റൊരു ഭാഗത്തേക്ക് എളുപ്പത്തിൽ പകർത്താം.
M1.02: Formatting & Project Certificate Creation
  • Drop Cap: A large capital letter at the beginning of a text block that has the depth of two or more lines of regular text.
  • Character Spacing: Adjusting the space between characters (Expanded/Condensed).
  • Header & Footer: Areas in the top and bottom margins of each page in a document.
  • Text Effects: Adding shadows, glows, or reflections to text.
Task: Create a Certificate 1. Set Page Orientation to Landscape.
2. Add a Page Border (Design > Page Borders).
3. Use WordArt for the title "CERTIFICATE".
4. Use Font formatting (Bold, Italic, Center Align).
M1.03: Tables, Styles & Tracking
  • Tables: Insert > Table. Used for organizing data in rows and columns.
  • Hyperlinks: Links to other files or websites (Ctrl + K).
  • Track Changes: A tool that records all edits made to a document, useful for collaborative work.
  • Bullets & Numbering: Used for creating lists.
M1.04: Newsletters & Layouts
  • Newspaper Columns: Page Layout > Columns. Splits text into vertical blocks.
  • Table of Contents (TOC): Automatically generated based on Heading Styles.
  • WordArt: Decorative text that can be added to a document.
M1.05: Forms & Mail Merge

Mail Merge: A feature that allows you to create personalized letters or labels for a large number of recipients using a single template and a data source (like an Excel list).

Malayalam support: Mail Merge ഉപയോഗിച്ച് ഒരേ കത്ത് ഒരേസമയം ഒരുപാട് ആളുകൾക്ക് അവരുടെ പേരും വിലാസവും ഉൾപ്പെടുത്തി അയക്കാൻ സാധിക്കും.

Module 2: Spreadsheets (CO2)

Duration: 15 Hours

M2.01 & M2.02: Excel Orientation & Scheduling

Excel is a spreadsheet program used to record and analyze numerical and statistical data.

  • Cell: The intersection of a row and a column.
  • Auto Fill: A feature that allows you to quickly fill a range of cells with a series of data (e.g., days of the week).
  • Summation: Using the AutoSum (Σ) button to add values.

M2.04 & M2.05: Performance Analysis & Pivot Tables
  • Freeze Panes: Keeps specific rows or columns visible while scrolling.
  • Conditional Formatting: Changes the appearance of cells based on specific conditions (e.g., highlighting marks > 40 in green).
  • Pivot Tables: A tool used to summarize, analyze, explore, and present summary data.
  • Data Validation: Restricts the type of data or the values that users enter into a cell.

Module 3: Presentations (CO3)

Duration: 10 Hours

M3.01 & M3.02: PPT Orientation & Media
  • Slide Layouts: Predefined arrangements for slide content (Title, Content, Two Content).
  • Auto Shapes: Ready-made shapes like arrows, stars, and flowcharts.
  • Inserting Media: Insert > Audio/Video. Enhances the presentation impact.
M3.03: Master Layouts & Animations
  • Slide Master: The top slide that stores information about the theme and slide layouts. Editing the Slide Master affects all slides.
  • Slide Transition: The visual effect that occurs when moving from one slide to the next.
  • Custom Animation: Effects applied to individual elements on a slide (Entrance, Emphasis, Exit).
  • Auto Rehearsing: Setting slide timings by practicing the presentation.

Module-wise Practice Questions

Module 1: Word

What is Mail Merge? (3 Marks)
Mail Merge is a feature in MS Word used to create multiple documents (like letters, envelopes, or labels) at once. It combines a 'Main Document' (template) with a 'Data Source' (list of names/addresses) to produce personalized outputs for each entry in the data source.
Explain the use of 'Format Painter'. (2 Marks)
Format Painter is used to copy formatting (font, size, color, etc.) from one piece of text and apply it to another. It saves time when you want consistent styling across a document.

Module 2: Excel

What is VLOOKUP? (5 Marks)
VLOOKUP stands for 'Vertical Lookup'. It is a function that searches for a specific value in the first column of a table range and returns a value in the same row from a specified column.
Syntax: =VLOOKUP(lookup_value, table_array, col_index_num, [range_lookup])

Module 3: PPT

What is a Slide Master? (3 Marks)
Slide Master is the primary slide in a hierarchy of slides that stores information about the theme and slide layouts of a presentation. Changes made to the Slide Master (like adding a logo or changing font) are automatically applied to all slides in the presentation.
