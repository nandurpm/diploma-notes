Module-wise Q&A

Q1: What is the main advantage of Mail Merge? (CO1)
It allows the mass production of personalized letters or labels quickly by linking a template to a database, saving time and reducing manual errors.
Q2: Explain the difference between COUNT and COUNTA in Excel. (CO2)
COUNT only counts cells containing numbers. COUNTA counts all non-empty cells (numbers, text, errors, etc.).
Q3: What is a 'Slicer' in an Excel Dashboard? (CO3)
A Slicer is a visual filtering tool used with Pivot Tables and Dashboards to filter data with a single click.
Q4: What is a Primary Key in MS Access? (CO4)
A Primary Key is a field that uniquely identifies each record in a table. It cannot contain null values or duplicate data.

Practice Model Paper

(Not an official examination paper)

Part A (Word - 10 Marks): Create a formal meeting notice. Use Mail Merge to address it to 5 different department heads listed in an Excel sheet.

Part B (Excel - 20 Marks): Create a table with 'Product Name', 'Price', and 'Quantity'. Calculate 'Total'. Use an IF statement to apply a 10% discount if Total > 5000.

Part C (Access - 10 Marks): Create a table 'Employees'. Fields: EmpID (PK), Name, Salary. Insert 5 records. Write a query to show employees with Salary > 25000.
