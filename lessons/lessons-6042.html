Course Overview

What this course is really teaching

IoT is not just connecting a device to Wi-Fi. It is an engineering chain: sensing the physical world, converting it into electrical data, processing it using a controller, sending it through a protocol, storing or displaying it, and controlling an output safely.

Official Identity

  • Program: Diploma in Electronics Engineering / Electronics and Communication Engineering.
  • Course Code: 6042A. Site filename uses base code 6042.
  • Course Title: Concepts of IoT.
  • Semester: 6. Credits: 4.
  • Category: Open Elective.
  • Periods per week: 4. Periods per semester: 60.

Learning Target

The syllabus wants students to explain IoT, identify boards like Arduino and Raspberry Pi, interface sensors/actuators and understand IoT applications in home automation, cities, energy and agriculture.

ഈ വിഷയത്തിൽ പ്രധാനമായി പഠിക്കേണ്ടത്: sensor data എടുക്കുക, controller ഉപയോഗിച്ച് process ചെയ്യുക, network വഴി അയയ്ക്കുക, actuator control ചെയ്യുക.

Professional Use

For an electrical/electronics drawing or escalator engineer, IoT knowledge helps in remote monitoring, predictive maintenance, smart energy metering, fault alarms, panel temperature monitoring, motor status logging and service dashboards.

How to study this handbook

  1. First understand the architecture: Device layer, network layer, cloud layer and application layer.
  2. Then study boards: Arduino Uno/Nano for simple I/O, NodeMCU for Wi-Fi IoT, Raspberry Pi for Linux-level IoT gateways.
  3. Learn sensor input type before circuit design: analog, digital, pulse, serial, I2C or SPI.
  4. Learn actuator output protection: relay driver, transistor driver, flyback diode, optocoupler isolation and proper power supply separation.
  5. Practice writing small Arduino programs and draw block diagrams for each application.

Module 1 • CO1 • 14 Hours

Internet of Things Fundamentals

M1.01 Differentiate IoT and M2M. M1.02 Explain architecture and platforms. M1.03 List challenges.

1.1 Definition of IoT

Internet of Things is a network of physical objects embedded with sensors, actuators, controllers and communication modules that collect data, exchange data and perform actions through internet or local network services.

A thing can be a smart meter, motor panel, room light, gas detector, irrigation valve, escalator controller, wearable health device, parking sensor or industrial temperature monitor.

IoT എന്നു പറഞ്ഞാൽ ഒരു device internet connect ചെയ്താൽ മാത്രം അല്ല. അത് physical world data sense ചെയ്യണം, process ചെയ്യണം, communication ചെയ്യണം, useful action/result നൽകണം.

1.2 Basic IoT Characteristics

  • Connectivity: Device communicates using Wi-Fi, Bluetooth, cellular, Ethernet or other networks.
  • Sensing: Physical quantity is converted into electrical signal.
  • Intelligence: Controller or cloud logic makes decisions.
  • Actuation: Output device changes real-world condition.
  • Identity: Each device must be identifiable using device ID, address or topic.
  • Scalability: System should support many devices without collapse.

1.3 IoT vs M2M Communication

PointM2MIoT
MeaningMachine-to-machine communication, usually between fixed industrial devices.Internet-connected devices exchanging data with apps, cloud and other systems.
NetworkOften closed networks such as RS232, RS485, GSM, proprietary links.Mostly IP-based networks, Wi-Fi, Ethernet, cellular and internet services.

1.4 IoT Architecture

  1. Perception layer: Sensors and actuators interact with the physical world.
  2. Network layer: Communication modules send data.
  3. Processing layer: Edge device, gateway or cloud processes data.
  4. Application layer: Dashboard, mobile app, alarms, reports and control.
  5. Security layer: Authentication, encryption and access control must protect every layer.

1.5 IoT Platforms

An IoT platform helps connect devices, collect data, visualize status, issue control commands and manage devices. Examples include Arduino IoT Cloud, Blynk, ThingSpeak, AWS IoT, Azure IoT, Google Cloud IoT-style services, ThingsBoard and Node-RED-based dashboards.

  • Device management: register devices, assign IDs and credentials.
  • Data ingestion: receive sensor values using MQTT/HTTP.
  • Storage: save time-stamped data.
  • Visualization: charts, indicators, alarms and maps.
  • Automation: if temperature is high, turn on fan or send alert.

1.6 Challenges in IoT

  • Power supply: battery life, sleep mode, stable voltage.
  • Network reliability: weak Wi-Fi, interference, packet loss.
  • Security: default passwords, unencrypted data, unauthorized access.
  • Scalability: many devices sending data at the same time.
  • Data accuracy: sensor calibration, noise and environmental effects.
  • Maintenance: firmware updates, replacement and fault diagnosis.

Module 2 • CO2 • 15 Hours

Microcontrollers and Prototyping Boards

Microcontroller concept, Arduino Uno, Arduino Nano, NodeMCU and Raspberry Pi features.

2.1 Microcontroller Meaning

A microcontroller is a compact computer on a chip containing CPU, memory, input/output ports, timers and serial communication blocks. It is meant for direct control of hardware devices.

Typical examples: ATmega328P, ATmega32, PIC16F877A, ESP8266, ESP32, ARM Cortex-M controllers.

Microcontroller = CPU + Flash/ROM + RAM + I/O Ports + Timers + ADC + Communication blocks

2.2 Microcontroller vs Microprocessor

PointMicrocontrollerMicroprocessor
UseEmbedded controlGeneral computing
Memory/I/OUsually built-inUsually external or chipset dependent
PowerLow power possibleHigher power
ExampleArduino ATmega328PComputer CPU
IoT roleReads sensors and controls outputsRuns operating systems and heavy applications

Arduino Uno

  • ATmega328P based development board.
  • 14 digital I/O pins, 6 analog inputs.
  • 5 V logic, USB programming.
  • Good for learning sensors, relays, LEDs and basic automation.

Arduino Nano

  • Small form factor ATmega328P board.
  • Breadboard friendly.
  • Similar programming style to Uno.
  • Useful where panel space or prototype area is limited.

NodeMCU

  • ESP8266 Wi-Fi board.
  • 3.3 V logic; do not directly feed 5 V signals to GPIO.
  • Used for Wi-Fi IoT, web server, MQTT and cloud dashboards.
  • Limited analog input compared with Arduino.

2.3 Raspberry Pi

Raspberry Pi is a single-board computer, not just a microcontroller board. It runs Linux, supports HDMI, USB, camera interface, Ethernet/Wi-Fi/Bluetooth depending on model and can act as an IoT gateway.

  • Better for image processing, database, dashboards and gateway applications.
  • Needs proper shutdown and reliable 5 V power supply.
  • GPIO is usually 3.3 V logic, so level shifting may be required.
  • Can communicate with Arduino through USB serial, I2C or UART.

Module 3 • CO3 • 15 Hours

Sensors, Actuators and Protocol Modules

Analog/digital sensors, Arduino interfacing, relay/LED/buzzer/motors, shields and RS232, Bluetooth HC-05, Wi-Fi ESP8266.

3.1 Sensor Basics

A sensor converts a physical quantity into an electrical signal. Sensors may produce analog voltage, digital HIGH/LOW, pulse frequency, PWM signal or serial data.

LDRLightAnalog voltageAutomatic lighting.

Soil moistureWater contentAnalog/digitalIrrigation.

3.2 Actuator Basics

An actuator converts an electrical signal into physical action. Since microcontroller pins cannot directly drive heavy loads, driver circuits are compulsory.

  • LED: Current limiting resistor required.
  • Buzzer: Direct if current is low; transistor driver if current is high.
  • Relay: Transistor driver + flyback diode + isolated contacts.
  • DC motor: Motor driver, MOSFET or H-bridge required.
  • Servo motor: PWM signal with separate stable supply.
Never connect a relay coil, motor or high-current load directly to Arduino I/O pin. It may destroy the controller.

3.3 Analog Sensor to Arduino

Arduino ADC converts analog voltage into a digital number. For Uno/Nano, ADC is normally 10-bit, so 0 to 5 V becomes 0 to 1023.

ADC count = (Vin / Vref) × 1023
Vin = (ADC count × Vref) / 1023
// Example: read analog sensor on A0
int raw = analogRead(A0);
float voltage = raw * 5.0 / 1023.0;
Serial.println(voltage);
Analog sensor വായിക്കുമ്പോൾ raw ADC value മാത്രം പറയരുത്. അതിനെ voltage/temperature/distance പോലുള്ള physical value ആക്കി explain ചെയ്യണം.

3.4 Relay Interfacing Logic

  1. Arduino output pin gives logic signal.
  2. Base/gate resistor drives transistor or MOSFET.
  3. Transistor energizes relay coil from external supply.
  4. Flyback diode protects driver from coil back EMF.
  5. Relay contact switches AC/DC load through proper rating.

RS232

Serial communication standard used in older computers/instruments. Arduino UART is TTL level, so MAX232 or proper converter is needed for real RS232 voltage levels.

Bluetooth HC-05

Short-range wireless serial module. Commonly used for mobile-to-Arduino control. Pairing, baud rate and TX/RX cross connection are important.

Wi-Fi ESP8266

Wi-Fi module/board for internet connectivity. Can be used as a standalone NodeMCU board or as a Wi-Fi module controlled by another controller.

3.6 Shields and Modules

A shield is an add-on board that plugs over an Arduino board to add functions like motor driving, Ethernet, relay, GSM or sensor connection. A module is a smaller breakout board for one function such as HC-05, relay module, DHT sensor module or ESP8266 module.

Advantage: reduces soldering and speeds up prototype building. Disadvantage: students may ignore actual circuit theory. Always understand the pin, supply, output type and current rating.

Module 4 • CO4 • 14 Hours

Domain Specific IoT Applications

Home automation and security, smart city, smart energy and smart agriculture.

4.1 Home Automation and Security

Home automation uses sensors and controllers to monitor and control electrical loads. Security systems detect intrusion, smoke, gas leakage or abnormal conditions and send alarm notifications.

  • Smart lighting based on occupancy and light level.
  • PIR sensor for intrusion detection.
  • Smoke/gas sensor for safety alarm.
  • Door contact sensor for entry monitoring.
  • Relay/triac/MOSFET driver for output switching.
  1. Sensor detects event.
  2. Controller verifies threshold or logic.
  3. Cloud/app receives event.
  4. User gets alert.
  5. Actuator is switched if needed.

4.2 Smart City

Smart city IoT applies sensors, connectivity and analytics to city infrastructure.

Smart Parking

Detect slot occupancy using ultrasonic, IR or magnetic sensors and display availability to users.

Smart Lighting

Street lights can dim, switch or report faults based on time, motion and ambient light.

Smart Roads

Traffic, pollution, weather, road condition and accident data are monitored.

Waste Monitoring

Bin fill level sensors help optimize collection route.

4.3 Smart Energy

Smart energy systems use IoT for monitoring, metering, fault detection and load optimization.

  • Smart meter: measures energy and sends usage data automatically.
  • Smart grid: integrates generation, storage, distribution and consumers using communication.
  • Load monitoring: identifies overloading and abnormal usage.
  • Maintenance: alarms for panel temperature, voltage drop, power failure and tampering.
Electrical field-ൽ IoT ഏറ്റവും useful ആകുന്നത് smart metering, panel monitoring, fault alert, preventive maintenance എന്നിവയിലാണ്.

4.4 Smart Agriculture

Smart irrigation uses soil moisture, temperature and humidity data to control water usage automatically.

  1. Soil moisture sensor measures water content.
  2. Controller compares value with threshold.
  3. If dry, relay switches pump/solenoid valve.
  4. System logs water usage and status.
  5. Farmer receives app/SMS/dashboard notification.

Benefits include reduced water wastage, labour saving, timely irrigation and better crop monitoring.

Formula and Data Bank

Useful calculations for IoT practicals

ADC Conversion

ADC count = Vin/Vref × (2ⁿ − 1)

For 10-bit ADC with 5 V reference, max count is 1023.

Voltage Divider

Vout = Vin × R2 / (R1 + R2)

Used with LDR, thermistor and level shifting.

LED Resistor

R = (Vs − Vf) / If

Never connect an LED without current limit.

Ultrasonic Distance

Distance = (Time × Speed of Sound) / 2

Division by 2 is needed because pulse travels to object and back.

Data Rate Estimate

Daily data = Packet size × samples per day

Useful for cloud planning and network traffic.

Relay Driver

Base current ≈ Collector current / forced gain

Choose driver with enough margin; add diode across coil.

Build Guide

Arduino IoT practical workflow

Use this approach when drawing or explaining any IoT prototype.

5.1 Temperature Monitoring Node

  1. Connect temperature sensor to Arduino analog/digital input.
  2. Read sensor value and convert into temperature.
  3. Display value in serial monitor or LCD.
  4. Send value to Wi-Fi module/cloud if internet is required.
  5. Trigger buzzer/relay if temperature crosses limit.
int raw = analogRead(A0);
float voltage = raw * 5.0 / 1023.0;
float temperatureC = voltage * 100.0; // LM35 approximation
if(temperatureC > 45){ digitalWrite(8,HIGH); }
else{ digitalWrite(8,LOW); }

5.2 Smart Light Logic

  1. LDR measures ambient light.
  2. PIR detects human presence.
  3. Controller checks both conditions.
  4. If it is dark and motion is detected, relay switches light.
  5. After delay, light turns off automatically.
int light = analogRead(A0);
int motion = digitalRead(2);
if(light < 400 && motion == HIGH){ digitalWrite(8,HIGH); }
else{ digitalWrite(8,LOW); }

5.3 IoT Design Checklist

  • Define the problem clearly.
  • Select sensor according to physical quantity and range.
  • Select controller according to I/O count, memory, speed and connectivity.
  • Use correct supply voltage and current rating.
  • Protect outputs using driver circuits and isolation.
  • Choose communication method based on range, cost and reliability.
  • Add data format, device ID, timestamp and alarm threshold.
  • Test offline first, then connect to cloud.

5.4 Industrial Drawing Engineer Note

For panel or escalator-related IoT monitoring, the drawing must show power supply, isolation boundary, terminal numbers, sensor type, controller I/O pins, communication module, relay/driver details, earthing and cable routing. Do not show only a block diagram when wiring accuracy is required.

Brutal truth: most student IoT projects look good on YouTube but fail in real equipment because they ignore isolation, surge protection, cable length, terminal labeling and maintenance access.

Answer Key

Concise answer guide

Part A answers
  1. IoT is a network of physical things with sensors, actuators, controllers and communication modules that collect and exchange data.
  2. M2M is usually closed device-to-device communication; IoT is internet/cloud/app integrated communication.
  3. Arduino IoT Cloud, ThingSpeak, Blynk, AWS IoT, ThingsBoard.
  4. A microcontroller is a single-chip computer with CPU, memory, I/O and peripherals for control applications.
  5. ATmega328P, USB programming, digital/analog I/O, 5 V logic.
  6. NodeMCU is an ESP8266-based Wi-Fi development board.
  7. Analog sensors and digital sensors.
  8. Actuator converts electrical control signal into physical action.
  9. HC-05 Bluetooth and ESP8266 Wi-Fi.
  10. Smart parking and smart street lighting.
Part B and C answer writing method

For 6-mark answers, write definition, block diagram/flow, 4 to 5 points and one application. For 10-mark answers, write introduction, neat diagram, working step-by-step, advantages, limitations and conclusion.

Important: IoT application answers must always include sensor, controller, communication, cloud/app and actuator/output.
