Course Overview

What this subject teaches

Microcontroller and Applications teaches how a small programmable chip controls hardware. The 8051 is used to learn architecture, assembly programming, timers, serial communication and device interfacing.

Main purpose

Understand 8051 blocks, write simple ALP programs, use timers/UART and interface devices such as motors, keyboard, LCD, ADC, DAC and LM35.

Industrial value

Microcontrollers appear in indicators, sensor modules, battery chargers, measurement instruments, automation cards and machine controllers.

Drawing engineer value

This helps with controller pinouts, I/O wiring, sensor interfaces, LCD/keypad wiring, serial connector drawings and troubleshooting flow.

Blunt warning: 8051 cannot be learned by reading only theory. You must draw the memory map, understand ALP structure, trace registers and understand how pins connect to hardware.
Study Method

How to study this handbook

Correct learning order

  1. Compare microprocessor and microcontroller.
  2. Memorize 8051 features and block diagram.
  3. Study internal RAM, program memory, SFR and PSW.
  4. Learn ALP structure and addressing modes.
  5. Practise arithmetic, logical, jump, call and bit instructions.
  6. Study interrupts, timers and serial communication.
  7. Connect hardware: motors, keyboard, LCD, ADC, DAC and LM35.

Exam answer method

  1. Start with definition or purpose.
  2. Draw labelled block/circuit diagram.
  3. Explain data flow step-by-step.
  4. For ALP, show register usage.
  5. For timer calculation, show machine cycle and count.
  6. For interfacing, write hardware role and software logic.

CO1 • Architecture • Memory • PSW

Module 1 - Features and Block Diagram of 8051

Explain 8051 architecture and memory organization. Total syllabus load: 12 hours.

Core idea

A microcontroller is a complete small computer on a chip. It contains CPU, memory, I/O ports, timers, serial port and interrupt control. 8051 is an 8-bit microcontroller widely used for learning embedded systems.

Microcontroller-ൽ CPU, memory, ports, timer, serial interface എല്ലാം ഒരേ chip-ൽ ഉണ്ടാകും. Compact control system design ചെയ്യാം.

Microprocessor vs microcontroller

Microprocessor mainly contains CPU and needs external memory/I/O. Microcontroller integrates CPU, RAM, ROM, ports, timers and serial interface on one chip.

8051 features

8-bit CPU, 4 KB program memory, 128 bytes internal RAM, 32 I/O lines, two 16-bit timers, serial port, interrupt system and bit-addressable memory.

Program memory

Stores instruction code. Classic 8051 has 4 KB on-chip ROM and supports external program memory using PSEN and EA pins.

Data memory

Internal RAM contains register banks, bit-addressable area and general-purpose RAM. SFR area controls ports, timers, serial port and interrupts.

PSW register

Program Status Word contains CY, AC, F0, RS1, RS0, OV, unused bit and P flag.

I/O ports

Ports P0, P1, P2 and P3 provide 32 I/O pins. P3 pins also support alternate functions: INT0, INT1, T0, T1, RXD, TXD, WR and RD.

Assembly language programming controls registers, memory and I/O pins directly. It is useful for understanding exact hardware-level operation and troubleshooting.

ALP structure

A typical program contains ORG directive, labels, instructions, comments, subroutines and END directive.

Addressing modes

Immediate, register, direct, register indirect, indexed and bit addressing are commonly used.

Instruction groups

Data transfer, arithmetic, logical, compare, rotate, swap, branch, call/return and bit-level instructions.

Jumps and loops

SJMP and LJMP are unconditional. JZ, JNZ, JC, JNC, CJNE and DJNZ are used for conditional branching and loops.

Subroutines

CALL transfers control to subroutine. RET returns. Stack stores return address automatically.

Delay generation

Delay is generated using instruction machine cycles and loops. Timers give more accurate delays than software loops.

Addressing modes

Instruction examples

  • Data transfer: MOV, MOVX, MOVC, PUSH, POP
  • Arithmetic: ADD, ADDC, SUBB, INC, DEC, MUL, DIV
  • Logical: ANL, ORL, XRL, CPL, CLR
  • Rotate/swap: RL, RLC, RR, RRC, SWAP
  • Branch: SJMP, LJMP, JZ, JNZ, JC, JNC, DJNZ, CJNE
  • Bit: SETB, CLR, CPL, JB, JNB, JBC

Module 3 - Interrupts, Timers and Serial Communication

Explain interrupt system, timer registers, timer delay and serial communication. Total: 14 hours.

Core idea

Interrupts let the 8051 respond to events. Timers generate accurate delays or count pulses. Serial communication transfers data through RXD and TXD.

Polling-ൽ CPU repeatedly check ചെയ്യും. Interrupt-ൽ event വന്നാൽ CPU ISR execute ചെയ്യും. Timer delay software loop-നെക്കാൾ accurate ആണ്.

Interrupt concept

An interrupt temporarily stops the main program, executes Interrupt Service Routine and returns using RETI.

8051 interrupts

External interrupt 0, Timer 0, External interrupt 1, Timer 1 and Serial interrupt. IE enables interrupts; IP sets priority.

TMOD register

Controls timer/counter selection, gate control and timer mode for Timer 0 and Timer 1.

TCON register

Contains timer run control and overflow flags: TR0, TF0, TR1, TF1 plus external interrupt flags and type control bits.

Timer modes

Mode 0: 13-bit, Mode 1: 16-bit, Mode 2: 8-bit auto reload, Mode 3: split timer mode.

Serial communication

8051 serial port uses SBUF and SCON. RXD and TXD pins transfer serial data. Level conversion is used for standard serial connectors.

Interrupt vector addresses

Serial SFRs

  • SBUF: serial data buffer.
  • SCON: serial control register with RI/TI flags.
  • PCON: SMOD bit doubles baud rate.
  • TH1: commonly loaded for baud-rate generation.
  • RXD: receive pin; TXD: transmit pin.

Module 4 - Interfacing I/O Devices with 8051

Illustrate practical interfacing of I/O devices with 8051. Total: 15 hours + 1 series test.

Core idea

Interfacing connects the 8051 to real-world devices. Direct connection is not always possible, so driver stages, current limiting, level conversion, ADC, DAC and proper timing are required.

8051 port current limited ആണ്. Motor, relay, stepper പോലുള്ള loads direct ആയി port-ലേക്ക് connect ചെയ്യരുത്. Driver circuit ഉപയോഗിക്കണം.

Stepper motor

Moves in fixed angular steps. 8051 outputs step sequence through a driver stage. Direction depends on sequence order.

DC motor speed control

Speed can be controlled by PWM. 8051 produces PWM and driver controls motor supply power.

4x4 matrix keyboard

Uses row and column lines. Controller scans rows and reads columns to identify the pressed key.

16x2 LCD

Displays 16 characters per line and 2 lines. Uses RS, RW, E and data pins. Can operate in 8-bit or 4-bit mode.

ADC and DAC

ADC converts analog signal to digital data. DAC converts digital value into analog voltage.

LM35 temperature system

LM35 gives 10 mV per degree Celsius. ADC converts this voltage for 8051 processing and display/control.

Answer Key

Complete model answers - condensed exam format

1. Microcontroller

A microcontroller is a single-chip computer containing CPU, memory, I/O ports and peripherals. Advantages: compact size, low cost, low power and less external hardware.

2. Features of 8051

8-bit CPU, 4 KB on-chip ROM, 128 bytes RAM, 32 I/O lines, two 16-bit timers, serial port, five interrupt sources and bit-addressable memory.

3. PSW

Program Status Word stores status flags: CY, AC, F0, RS1, RS0, OV and P.

4. Addressing modes

MOV A,#25H uses immediate addressing. MOV A,30H uses direct addressing.

5. DJNZ

DJNZ decrements a register or memory location and jumps if result is not zero. It is used for loops and delay generation.

6. Interrupt and ISR

Interrupt diverts CPU from main program. ISR is the service routine executed for that interrupt and ends with RETI.

7. TMOD and TCON

TMOD selects timer/counter mode and operation. TCON contains timer run bits, overflow flags and external interrupt control flags.

8. SBUF

SBUF is serial buffer register. Writing to SBUF starts transmission; reading SBUF gives received data.

9. Stepper driver

8051 port current is small and cannot drive motor coils directly. Driver stage supplies required current and protects the controller.

10. LM35 sensitivity

LM35 produces 10 mV per degree Celsius.

11. Microprocessor vs microcontroller

Microprocessor mainly contains CPU and needs external RAM, ROM and I/O. Microcontroller integrates CPU, memory, I/O and peripherals on one chip.

12. Internal RAM

00H-1FH register banks, 20H-2FH bit-addressable RAM, 30H-7FH general RAM, 80H-FFH SFR space.

13. PSW register

PSW contains CY, AC, F0, RS1, RS0, OV, reserved bit and P. RS bits select register bank; CY is carry; OV is overflow; P is parity.

14. Addressing modes

Immediate, register, direct, indirect, indexed and bit addressing modes are used. Example: MOV A,#55H is immediate; MOV A,R2 is register; SETB P1.0 is bit addressing.

15. Addition and subtraction logic

Addition loads first data to accumulator, uses ADD with second data and stores result. Subtraction clears carry/borrow, loads first data, uses SUBB with second data and stores result.

16. Interrupt sources

INT0 at 0003H, Timer0 at 000BH, INT1 at 0013H, Timer1 at 001BH and serial interrupt at 0023H.

17. Timer modes

Mode 0 is 13-bit, Mode 1 is 16-bit, Mode 2 is 8-bit auto-reload and Mode 3 is split timer mode.

18. Matrix keyboard

Rows and columns are connected to I/O pins. Controller scans one row at a time and reads columns. Row-column combination identifies key press.

19. 8051 block diagram

8051 contains CPU, program memory, data RAM, SFRs, four I/O ports, timers, serial port, interrupt controller, oscillator and internal bus.

20. Instruction types

Instruction types include data transfer, arithmetic, logical, rotate, swap, compare, branch, call and bit instructions. Multiplication and division use accumulator and B register.

21. Jump, call and delay

Jump changes program flow. Loop repeats instructions. CALL transfers to subroutine and RET returns. Delay can be generated using machine cycles and nested loops.

22. Interrupt handling

CPU completes current instruction, saves program counter, jumps to vector address, executes ISR and returns using RETI. IE enables interrupts; IP sets priority.

23. Serial communication

8051 UART uses TXD/RXD pins. SCON controls mode and RI/TI flags. SBUF holds data. PCON SMOD affects baud rate.

24. Interfacing

Stepper/DC motors need drivers. LCD uses RS, RW, E and data lines. ADC converts sensor voltage to digital data. DAC converts digital output to analog. LM35 voltage is read through ADC.
