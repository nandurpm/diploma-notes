Course Overview

What this subject teaches

Core aim

Understand 8051 internal blocks, memory organization and registers; write simple ALP; use timer/interrupt/UART features; and explain interfacing with common I/O devices.

Industrial value

Microcontrollers appear in control cards, indicators, battery chargers, safety modules, medical instruments, sensor units, automation boards and machine controllers.

Drawing engineer value

This helps you read controller pinouts, I/O wiring, common lines, sensor interfaces, relay/motor drivers, LCD/keypad connections and RS232 communication wiring.

No shortcut: You need three skills together: draw the block/memory map, trace ALP register changes, and explain how port pins connect to actual hardware.
Study Method

How to use this handbook

Correct learning order

  1. Compare microprocessor and microcontroller.
  2. Memorize 8051 features, block diagram and port role.
  3. Study internal RAM, program memory, SFR and PSW.
  4. Learn ALP structure, labels and comments.
  5. Master addressing modes before programs.
  6. Practise arithmetic, logic, jump, call, delay and bit instructions.
  7. Study interrupt sequence, timer modes and serial SFRs.
  8. Finish with practical interfacing circuits and software logic.

Exam answer method

  1. Start with definition or purpose.
  2. Draw labelled diagram or register format.
  3. Explain block-by-block or bit-by-bit.
  4. For ALP, write initialization, operation and result storage.
  5. For timer questions, show machine-cycle logic and count loading.
  6. For interfacing, show driver/protection and software sequence.

CO1 • Architecture • Memory • PSW

Module 1 - Features and Block Diagram of 8051

Compare microprocessor and microcontroller, list 8051 features, explain block diagram, data/program memory and PSW. Load: 12 hours.

Microprocessor vs microcontroller

Microprocessor mainly contains CPU and needs external RAM, ROM and I/O. Microcontroller integrates CPU, RAM, ROM, ports, timers and serial interface on one chip.

8051 features

8-bit CPU, 4 KB ROM, 128 bytes RAM, 32 I/O pins, two 16-bit timers/counters, serial port, five interrupts, bit-addressable RAM and Boolean processing.

Data memory

00H-1FH register banks, 20H-2FH bit-addressable area, 30H-7FH general RAM and 80H-FFH SFR space.

Program memory

Program memory stores instruction code. Reset starts at 0000H. Interrupt vectors are fixed low program-memory addresses.

PSW

Program Status Word contains CY, AC, F0, RS1, RS0, OV and P. RS1/RS0 select register bank.

I/O ports

P0-P3 provide 32 I/O pins. P3 has alternate functions RXD, TXD, INT0, INT1, T0, T1, WR and RD.

Expected Questions - CO1

  1. Compare microprocessor and microcontroller.
  2. List features of 8051.
  3. Draw and explain block diagram of 8051.
  4. Explain data memory and program memory organization.
  5. Explain PSW register and register bank selection.
CO2 • ALP • Addressing • Instructions

Module 2 - Assembly Language Programming for 8051

ALP structure, addressing modes, instructions, jump/loop/call/bit instructions, machine cycle, delay, data serialization and programs. Load: 17 hours + Series Test I.

ALP structure

ORG directive, labels, instructions, operands, comments, subroutines and END directive.

Addressing modes

Immediate, register, direct, indirect, indexed and bit addressing. Example: MOV A,#25H is immediate.

Instruction groups

Data transfer, arithmetic, logical, compare, rotate, swap, branch, call/return and single-bit instructions.

Jump and call

SJMP/LJMP are unconditional. JZ, JNZ, JC, JNC, CJNE and DJNZ are conditional. CALL uses stack and RET returns.

Machine cycle and delay

Instruction timing depends on machine cycles. Delay can be created using loops or timers.

Required programs

Addition, subtraction, multiplication, division, ASCII to packed BCD, packed BCD to ASCII, BCD/hex conversion, port reading and writing.

Expected Questions - CO2

  1. Explain ALP structure.
  2. Explain addressing modes with examples.
  3. Classify instructions.
  4. Explain jump, loop, call and bit instructions.
  5. Write ALP for arithmetic and conversion operations.
CO3 • Interrupts • Timers • Serial

Module 3 - Interrupts, Timers and Serial Communication

Interrupt concept, ISR, IE/IP, TMOD, TCON, timer modes, delay calculation, baud rate, RS232, SBUF, SCON and PCON. Load: 14 hours.

Interrupt concept

An interrupt temporarily stops the main program, executes ISR and returns using RETI.

IE and IP

IE enables global and individual interrupts. IP sets interrupt priority.

Timer modes

Mode 0 is 13-bit, Mode 1 is 16-bit, Mode 2 is 8-bit auto reload and Mode 3 is split mode.

TCON

TCON contains timer run bits, overflow flags and external interrupt control/status bits.

Serial communication

8051 uses RXD and TXD. SBUF stores data, SCON controls mode and flags, PCON affects baud rate.

RS232

RS232 needs level conversion because 8051 uses TTL logic levels.

Interrupt vector addresses

Reset0000H
INT00003H
Timer 0000BH
INT10013H
Timer 1001BH
Serial0023H

Interrupt execution

  1. Interrupt request occurs.
  2. CPU completes current instruction.
  3. CPU checks enable and priority.
  4. PC is pushed to stack.
  5. CPU jumps to vector address.
  6. ISR executes and RETI returns.
CO4 • Interfacing

Module 4 - Interfacing Various I/O Devices with 8051

Stepper motor, DC motor speed control, 4x4 keyboard, 16x2 LCD, ADC, DAC and LM35 temperature sensor interfacing. Load: 15 hours + Series Test II.

Stepper motor

8051 outputs coil excitation sequence through driver IC. Reversing sequence reverses direction.

DC motor

Speed is controlled using PWM through driver or H-bridge. Never connect motor directly to port.

4x4 keyboard

Four rows and four columns allow 16 keys. Controller scans rows and reads columns.

16x2 LCD

Uses RS, RW, E and data pins. Displays two lines of sixteen characters.

ADC and DAC

ADC converts analog voltage to digital data. DAC converts digital output to analog voltage.

LM35

LM35 gives 10 mV per degree Celsius. 8051 reads it through ADC for temperature display/control.

Interfacing checklist

  • Use driver for relay, DC motor and stepper motor.
  • Use flyback diode for inductive loads.
  • Use common ground for non-isolated modules.
  • Use current limiting resistor for LED/backlight.
  • Use ADC for analog sensors.
  • Debounce keyboard and switches in software.

Timer and conversion formulas

Clock

Machine cycle frequency = Crystal frequency / 12
Machine cycle period = 12 / Crystal frequency
For 11.0592 MHz: machine cycle ≈ 1.085 μs

Timer

Counts required = Delay / Machine cycle period
Initial count = 65536 - Counts required
TH = high byte, TL = low byte

Sensor

LM35 output = 10 mV / °C
ADC step size = Vref / 2ⁿ
DAC output ≈ Digital count × step size

Answer Key

Condensed model answers

1. Microcontroller

A microcontroller is a single-chip computer containing CPU, memory, I/O ports and peripherals. It is compact, low cost, low power and needs less external hardware.

2. Features

8-bit CPU, 4 KB ROM, 128 bytes RAM, 32 I/O lines, two 16-bit timers, serial port, five interrupts and bit-addressable memory.

3. PSW

Program Status Word stores CY, AC, F0, RS1, RS0, OV and P flags.

4. Addressing

MOV A,#25H is immediate addressing. MOV A,30H is direct addressing.

5. DJNZ

DJNZ decrements and jumps if result is not zero; used for loops and delays.

6. Interrupt and ISR

Interrupt diverts CPU from main program. ISR is the service routine and ends with RETI.

7. TMOD/TCON

TMOD selects timer mode and timer/counter operation. TCON controls timer run bits, overflow flags and external interrupt bits.

8. SBUF

SBUF stores transmit/receive serial data.

9. Driver

8051 port current is too low for motors. Driver stage supplies current and protects the controller.

10. LM35

LM35 output sensitivity is 10 mV per degree Celsius.

Memory organization

00H-1FH register banks, 20H-2FH bit area, 30H-7FH general RAM and 80H-FFH SFR space.

Interrupt vector

INT0 0003H, Timer0 000BH, INT1 0013H, Timer1 001BH, Serial 0023H.

Serial communication

8051 uses TXD/RXD. SCON controls mode and RI/TI; SBUF holds data; PCON SMOD affects baud rate; RS232 needs level conversion.

Interfacing

Motors need drivers, LCD uses RS/RW/E/data, keyboard uses row-column scan, ADC reads analog sensors, DAC outputs analog voltage and LM35 is read through ADC.
