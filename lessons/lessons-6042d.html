Course Overview

What this subject is really about

Multimedia is the engineering of text, audio, image, video and animation so that they can be created, stored, compressed, transmitted, synchronized and delivered through computers and networks.

Core idea

A multimedia system uses more than one form of information. A good system balances quality, file size, bandwidth, device capability and user experience.

Electronics link

Audio sampling, video bandwidth, compression, display systems, sensor capture, communication links and storage connect directly with electronics and communication engineering.

Industry link

Used in e-learning, product demos, technical manuals, HMI help screens, service dashboards, training simulators and digital documentation.

Module 1

Introduction to Multimedia and Multimedia Projects

CO1 target: explain components, applications, digital transition and project stages.

1.1 What is multimedia?

Multimedia is the integrated use of two or more media types such as text, graphics, image, animation, audio and video with computer-based control. If the user can navigate or control the presentation, it becomes interactive multimedia. If it uses linked nodes, it becomes hypermedia.

Multimedia = പല തരത്തിലുള്ള information ഒരുമിച്ച്, computer control ഉപയോഗിച്ച് present ചെയ്യുന്നത്. User click ചെയ്ത് path select ചെയ്യാൻ കഴിയുമെങ്കിൽ അത് interactive multimedia.

Components

  • Text: titles, labels, body content, captions, menus and hyperlinks.
  • Graphics: drawings, icons, vector diagrams, charts and interface elements.
  • Images: photographs, scanned images and raster graphics.
  • Audio: speech, music, effects and alerts.
  • Video: moving image sequence with synchronized audio.
  • Animation: synthetic motion using frames, objects or transformations.
  • Interactivity: buttons, menus, hyperlinks, forms, games and simulations.

1.2 Applications

Web multimedia appears in e-learning, product demonstrations, news portals, social platforms, webinars, advertisements, virtual labs, product manuals, medical records, digital libraries and entertainment portals.

Engineering example: an escalator service manual can contain procedure text, wiring diagram, photo, demonstration video, warning audio and clickable fault-navigation tree.

1.3 Conventional to digital media

Conventional media is fixed and mostly one-way. Digital media converts information into binary data, allowing storage, editing, compression, copying, search, networking and interactivity.

ConventionalDigital
Hard to edit without lossEasy to edit and reuse
Physical or one-way distributionWeb/mobile/network delivery
No direct indexingMetadata, tags and search
Copy quality degradesPerfect copies possible unless recompressed

1.4 Multimedia project stages

  1. Concept and requirement analysis.
  2. Planning: schedule, budget, asset list and platform.
  3. Design: storyboard, navigation map, layout and interaction.
  4. Content creation: text, audio, image, video and animation.
  5. Authoring and integration.
  6. Testing on devices and browsers.
  7. Delivery through web, mobile, LMS, kiosk or network.
  8. Maintenance and updates.

Hardware and software

Hardware

Camera, microphone, scanner, capture card, CPU, GPU, RAM, SSD, speaker, monitor, projector, network adapter and router.

Software

Image editor, audio editor, video editor, animation tool, presentation tool, screen recorder, web tool and authoring system.

Authoring tools

Used to assemble media, create navigation, add interaction and publish final output.

Card/page authoring

Organizes content as pages or cards. Useful for tutorials, kiosks and interactive manuals.

Module 2

Text, Hypertext, Audio and Data Compression

CO2 target: explain text, audio, recording, compression and transmission.

2.1 Text in multimedia

Text provides titles, navigation, instructions, captions, search keywords and accessibility support. Poor text design destroys a multimedia product even if the graphics are attractive.

  • Use readable size and contrast.
  • Use consistent font families.
  • Use short headings and captions.
  • Provide transcripts and alt text where required.

2.2 Fonts

TermMeaning
Font familyGroup of related type designs.
Font faceStyle within a family such as bold or italic.
Bitmap fontStored as pixels for fixed size.
Outline fontStored as curves and scalable.
UnicodeInternational character representation for many scripts.

2.3 Hypertext and hypermedia

Hypertext is linked text. Hypermedia extends this to text, audio, image, video and animation. A node is a unit of information, an anchor is the visible clickable part, and a link connects nodes.

2.4 Digital audio

Sound is a pressure wave. Digital audio is created by sampling the waveform at regular intervals and quantizing each sample into binary values.

Audio data rate = Sampling rate × Bit depth × Channels

Example: CD audio = 44,100 × 16 × 2 = 1,411,200 bit/s ≈ 1.411 Mb/s.

  • Frequency: cycles per second.
  • Bandwidth: range of frequencies required.
  • Decibel: logarithmic unit for sound/signal ratio.
  • Bit depth: bits used per sample.

2.5 Audio file formats

FormatTypeUse
WAVUsually uncompressed PCMEditing and mastering
MP3LossyMusic distribution
AACLossyStreaming/mobile
FLACLosslessArchival audio
MIDIInstruction/event dataSynthesized music

2.6 MIDI vs digitized audio

PointMIDIDigitized audio

2.7 Compression

Compression reduces file size by removing redundancy or less important information. Lossless compression reconstructs the original exactly. Lossy compression discards less noticeable information for higher reduction.

Compression ratio = Original size / Compressed size
Saving % = [(Original size - Compressed size) / Original size] × 100

Run-Length Coding

Replaces repeated values with count + value. Example: AAAAAABBBCC becomes 6A3B2C.

Huffman Coding

Uses shorter codes for frequent symbols and longer codes for rare symbols.

Dictionary Coding

Replaces repeated strings with dictionary references.

Arithmetic Coding

Encodes a message as a fractional number interval.

Sliding Window

Stores references to repeated sequences in recently processed data.

Silence Compression

Represents silent portions of audio compactly instead of transmitting full samples.

Module 3

Image Fundamentals, Colour and Compression

CO3 target: use image basics and compression methods.

3.1 Digital image basics

A digital image is a two-dimensional array of pixels. Quality depends on resolution, colour depth, dynamic range, compression and display characteristics.

  • Pixel: smallest picture element.
  • Resolution: width × height pixels.
  • Colour depth: bits per pixel.
  • Raster image: pixel based.
  • Vector graphic: object/shape based.
Uncompressed image size = Width × Height × Bits per pixel / 8 bytes

3.2 Colour models

ModelUse
RGBDisplays, cameras and web images.
CMYKPrinting.
HSV/HSLColour selection and editing.
GrayscaleDocuments, scanning and technical images.

Palette: limited table of colours. Dithering: simulating unavailable colours using patterns of available colours.

3.3 Lossless and lossy images

Lossless: exact recovery, good for diagrams and text. Lossy: smaller size by discarding data, good for photographs.

Diagram/text image-ക്ക് PNG നല്ലത്. Photo-ക്ക് JPEG. Archive/print quality-ക്ക് TIFF.

3.4 Image formats

FormatBest useNote
GIFSimple graphics/animationLimited colours
JPEGPhotosLossy, small size
PNGDiagrams/screenshotsLossless, transparency
TIFFScanning/archiveHigh quality, large

3.5 JPEG compression idea

  1. Convert RGB to luminance/chrominance.
  2. Divide image into 8 × 8 blocks.
  3. Apply Discrete Cosine Transform.
  4. Quantize DCT coefficients.
  5. Entropy-code the remaining values.

This works because human vision is less sensitive to small high-frequency colour changes than to brightness structure.

Module 4

Video, Animation and Multimedia Networks

CO4 target: explain video compression standards, animation and communication.

4.1 Video basics

Video is a sequence of still images displayed quickly to create motion. Important parameters: frame rate, resolution, aspect ratio, colour depth, bitrate, codec and container.

Raw video rate = Width × Height × Bits per pixel × Frames per second

Example: 1920 × 1080 × 24 × 30 ≈ 1.49 Gbit/s before compression.

4.2 Analog vs digital video

PointAnalogDigital
SignalContinuous waveformBinary data
CopyingQuality degradesCan copy without loss
EditingLess flexibleEasy non-linear editing
DeliveryBroadcast/tapeFiles, web and streaming

4.3 Video compression

Video compression removes spatial redundancy within frames and temporal redundancy between frames. Motion compensation stores reference frames, motion vectors and residual differences instead of complete frames.

MPEG-4 supports multimedia coding, object-based representation, internet delivery, video storage and interactive media.

4.4 Animation

MethodExplanation
Cell animationFrame-by-frame drawings or layers.
Computer animationObjects animated using software and keyframes.
MorphingSmooth transformation of one image/object into another.
3D animationModels, lighting, camera and rendering.

4.5 Multimedia networks

Multimedia networks must deliver continuous data. Important quality factors are bandwidth, delay, jitter, packet loss, buffering and synchronization.

Multimedia over IP

Packet network delivery for streaming, video conferencing, IPTV and MOD.

Multimedia over ATM

Uses fixed cells and quality of service concepts for voice, video and data.

Video conferencing

Requires camera, microphone, codec, network, display and low latency.

Media-on-Demand

User requests stored media and plays it when required.

Indexing and retrieval

Uses metadata, tags, thumbnails, timestamps and search.

Transmission quality

Depends on delay, jitter, packet loss, bitrate and sync.

Solved Examples

Numerical and application examples

Audio data rate

Find data rate for stereo audio sampled at 48 kHz with 16-bit samples.

48000 × 16 × 2 = 1,536,000 bit/s = 1.536 Mb/s

Image size

Find uncompressed size of 1024 × 768 RGB image with 24 bits/pixel.

1024 × 768 × 24 / 8 = 2,359,296 bytes ≈ 2.25 MiB

Compression ratio

60 MB video compressed to 12 MB.

Ratio = 60 / 12 = 5:1; Saving = 80%

Format decision

For a wiring-diagram screenshot in a technical manual, PNG is better than JPEG because it preserves sharp lines and labels without compression artifacts.

Answer Key

Short answer guide

Part A key points
  1. Computer-controlled integration of text, graphics, image, audio, video and animation.
  2. Authoring tools integrate media, navigation, interaction and publishing.
  3. Hypertext is linked text; anchor is clickable source; node is information unit.
  4. Sampling converts analog sound into discrete values at regular intervals.
  5. WAV, MP3, AAC, FLAC, MIDI.
  6. Compression ratio = original size / compressed size.
  7. Dithering simulates more colours using patterns.
  8. JPEG is lossy and good for photos; PNG is lossless and good for diagrams.
  9. Motion compensation stores movement and differences between video frames.
  10. Media-on-demand allows users to request and play stored media when needed.
Long answer writing pattern

For 6 marks: definition + 4 to 6 points + example. For 10 marks: definition + diagram/table + explanation + advantages/limitations + application.
