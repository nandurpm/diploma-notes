Module 1 • CO1 • 16 Hours

Power semiconductor devices, SCR triggering and commutation

Power semiconductor devices are controlled switches. In automation panels they are used for power conversion, motor control, heater control, welding control and UPS/inverter systems.

Power MOSFET

A power MOSFET is a voltage-controlled majority-carrier switching device. Gate current is practically negligible in steady state, but the gate capacitance must be charged and discharged during switching.

  • Terminals: Gate, Drain, Source.
  • Fast switching and simple gate drive.
  • Excellent for low-to-medium voltage choppers, SMPS and DC motor control.
  • ON-state represented by drain-source resistance RDS(on).
Pcond = I2 RDS(on)Used for MOSFET conduction loss estimate.
MOSFET gate drive weak ആണെങ്കിൽ device partially ON ആയിരിക്കും. അപ്പോൾ heating കൂടും. Panel troubleshooting-ൽ gate signal, heatsink temperature, load short എന്നിവ check ചെയ്യണം.

IGBT

An IGBT combines MOS gate control with bipolar conduction. It is common in medium/high-power motor drives because it gives easier gate drive than BJT and lower conduction loss than MOSFET at higher voltage.

  • Terminals: Gate, Collector, Emitter.
  • Used in VFDs, inverters, UPS, induction heating and traction drives.
  • Better for high voltage and high current compared with ordinary MOSFET.
  • Switching is slower than MOSFET due to tail current.
Exam line: MOSFET is preferred for high-speed low-voltage switching; IGBT is preferred for higher power inverter and drive applications.

SCR structure and operation

The SCR is a four-layer PNPN thyristor with three terminals: anode, cathode and gate. It behaves like a controlled rectifier. When forward biased, it remains OFF until triggered by gate current or another turn-on mechanism. After turn-on, it latches and remains ON until anode current falls below holding current.

SCR V-I terms

  • Forward blocking region: anode positive, device OFF.
  • Breakover voltage: voltage at which SCR turns ON without gate signal.
  • Latching current: minimum current needed immediately after triggering to keep SCR ON.
  • Holding current: minimum anode current below which SCR turns OFF.
  • Reverse blocking: reverse voltage applied, only leakage flows until breakdown.

Turn-on methods

  • Gate triggering: normal controlled method.
  • Forward voltage triggering: voltage exceeds breakover.
  • dv/dt triggering: junction capacitance current accidentally triggers SCR.
  • Thermal triggering: temperature increases leakage.
  • Light triggering: used in LASCR applications.
Common mistake: Gate pulse can turn SCR ON but cannot turn it OFF. Turn-off needs current to fall below holding current or forced commutation.

R, RC and UJT triggering

R triggering

Simple resistor limits gate current. It is cheap but firing angle control range is poor and gate power loss is higher.

RC triggering

Capacitor charges through variable resistance. When capacitor voltage reaches gate trigger level, SCR receives pulse. This gives better firing angle control.

UJT triggering

UJT relaxation oscillator generates sharp pulses. It gives stable triggering and better isolation when pulse transformer is used.

SCR commutation techniques

Commutation means turning OFF a conducting SCR by reducing its anode current below holding current for a sufficient turn-off time.

DIAC and TRIAC

A DIAC is a bidirectional trigger diode. It remains OFF until breakover voltage is reached in either polarity, then conducts. A TRIAC is like two SCRs connected in inverse parallel with common gate; it controls AC power in both half cycles.

TRIAC applications

  • AC lamp dimmer.
  • Fan speed controller.
  • Heater power controller.
  • Small AC motor control.

Limitations

  • Not suitable for very high frequency switching.
  • Needs snubber with inductive loads.
  • dv/dt false triggering must be avoided.
  • Gate triggering sensitivity differs by quadrant.

Controlled rectifiers, inverters, cycloconverters and choppers

This module is waveform-heavy. In every answer, write circuit purpose, current path, load type, waveform effect and application.

Single-phase controlled rectifier basics

A controlled rectifier converts AC to controlled DC using SCRs. The firing angle α delays conduction and controls average output voltage. With R load, current follows voltage. With RL load, current continues due to load inductance.

Vavg = (Vm / 2π)(1 + cos α)Single-phase half-wave controlled rectifier with R load.
Vavg = (2Vm / π) cos αSingle-phase full controlled bridge rectifier in continuous conduction.
Firing angle കൂട്ടിയാൽ output DC കുറയും. RL load-ൽ current sudden ആയി zero ആകില്ല; freewheeling diode current smooth ആക്കാൻ ഉപയോഗിക്കുന്നു.

Freewheeling diode

A freewheeling diode is connected across an inductive load to provide a path for current when the supply or SCR is not conducting. It reduces negative output voltage and improves current continuity.

  • Protects SCR from high inductive voltage.
  • Improves load current waveform.
  • Reduces ripple and improves load performance.
  • Common in DC motor and inductive load control.
Exam point: Always mention freewheeling diode when explaining RL load controlled rectifiers.

AC power control using SCR/TRIAC

AC power control changes the RMS voltage supplied to an AC load by phase control. The device is triggered at a delay angle in each half cycle. TRIAC is convenient for single-phase bidirectional control.

  • Used in heater control, lamp dimmers and fan control.
  • Output waveform is chopped sinusoidal voltage.
  • Harmonics increase when firing angle is high.
  • Snubber and EMI suppression are important in practical circuits.

Basic inverter

An inverter converts DC to AC. It is the heart of UPS, VFD, solar inverter and backup systems. The output may be square wave, modified square wave or PWM sine wave depending on control method.

  • VSI: Voltage Source Inverter, stiff DC voltage source.
  • CSI: Current Source Inverter, stiff DC current source.
  • Series inverter: commutation assisted by resonant load.
  • Parallel inverter: transformer and capacitors shape operation.

Dual converter and cycloconverter

Single-phase dual converter

A dual converter uses two controlled rectifiers connected in opposite directions. It provides reversible DC voltage and can operate in four quadrants. It is useful for reversible DC motor drives.

  • Converter 1 gives positive DC voltage.
  • Converter 2 gives negative DC voltage.
  • Circulating current can exist if both converters conduct.
  • Non-circulating current mode avoids simultaneous conduction.

Cycloconverter

A cycloconverter converts AC of one frequency directly to AC of another frequency without an intermediate DC link. Low-to-high frequency and high-to-low frequency concepts are studied; industrial use is mainly low frequency high power drives.

  • Direct AC-to-AC conversion.
  • Uses controlled rectifier groups.
  • Output waveform is built from supply segments.
  • Used in low-speed high-power applications.

Choppers

A chopper converts fixed DC into variable DC by high-speed switching. It is equivalent to a DC transformer. Output voltage is controlled by duty cycle.

Duty cycle, D = TON / T ; Step-down chopper Vo = D VsIncreasing ON time increases average output voltage.
Step-up chopper Vo = Vs / (1 − D)Ideal boost converter relation; practical value is lower due to losses.

Speed control techniques

  • DC series/shunt drive: speed controlled by armature voltage, field control or resistance control.
  • Stator voltage control: changes induction motor voltage, suitable for fan/pump type loads.
  • Rotor ON-OFF control: used in wound-rotor motor starting/speed control concepts.
  • VVVF control: variable voltage variable frequency control maintains V/f ratio and gives efficient speed control.

Induction heating, dielectric heating and resistance welding

Induction heating

Alternating magnetic field induces eddy currents in the metal workpiece. Heat is produced by I²R loss in the workpiece itself.

  • Fast and clean heating.
  • Localized heat.
  • Used for hardening, brazing, melting.

Dielectric heating

High-frequency electric field causes molecular friction in non-conducting material. Heat is generated inside the dielectric.

  • Used for plastics, wood, rubber, drying.
  • Uniform internal heating.
  • Requires high-frequency source.

Resistance welding

High current passes through metal joint. Heat is produced at contact resistance and pressure forms the weld.

  • Spot welding, seam welding, projection welding.
  • No filler material required.
  • Control of current/time/pressure is critical.

UPS operation: online and offline

Offline UPS

Normally the load is supplied directly from mains. When mains fails, the inverter starts supplying power from battery. There is a small transfer time.

  • Simple and low cost.
  • Suitable for personal computers and small loads.
  • Output quality depends on inverter design.

Online UPS

The load is always fed from inverter. Mains charges the battery and supplies the DC link through rectifier. There is no transfer interruption.

  • Best power conditioning.
  • No transfer time.
  • Used for servers, hospital equipment and critical automation.

Industrial troubleshooting angle

  • For drive faults, check input supply, DC bus, gate drive, heat sink, load jam and feedback sensor.
  • For heater control faults, check SCR/TRIAC short, gate trigger signal, snubber and temperature feedback.
  • For UPS faults, check battery health, charger, inverter output, bypass and earth leakage.
  • Never bypass interlocks during field testing. Temporary bypassing without documentation creates real accident risk.
Module 4 • CO4 • 13 Hours + Test

PLC architecture, instructions and ladder programs

PLC programming is not typing contacts randomly. The correct order is: understand process, list inputs and outputs, write sequence, add interlocks, then draw ladder.

PLC architecture

A PLC is an industrial controller that reads inputs, executes a stored program and updates outputs repeatedly. This repeating process is called the scan cycle.

  1. Input scan: reads switches, sensors and feedbacks.
  2. Program scan: solves ladder logic from left to right and top to bottom.
  3. Output scan: updates relays, contactors, lamps, valves and drive commands.
  4. Housekeeping: diagnostics, communication and memory tasks.

PLC advantages

  • Reliable in industrial environments.
  • Easy modification compared with relay panels.
  • Diagnostics and online monitoring are possible.
  • Supports timers, counters, compare, move, math and communication.
  • Reduces wiring complexity when logic is large.

NO, NC and latch logic

Start latch concept:
|--[/STOP]--[ START ]----+----( MOTOR )
|                        |
|                        +--[ MOTOR ]---|

STOP is normally closed in logic. START energizes MOTOR. MOTOR auxiliary contact seals the circuit.
Start button വിട്ടാലും motor ON ആയി തുടരണമെങ്കിൽ latch contact വേണം. Stop/fault contacts series-ൽ വയ്ക്കണം.

Timer logic

ON delay timer:
|--[ START ]----------------( TON T1, 5 s )
|--[ T1.DN ]----------------( OUTPUT )

Timer done bit becomes ON only after the preset time is reached. This is used for delayed motor start, traffic light timing and fluid level control.

Ladder program examples

1. Staircase lamp

Requirement: lamp can be switched from two locations. PLC logic can use two inputs A and B. Lamp is ON when A and B are different.

|--[ A ]--[/ B ]----+----( LAMP )
|                   |
|--[/ A ]--[ B ]----+
2. Conveyor start/stop with overload
|--[/STOP]--[/OVERLOAD]--[START]---+---( CONVEYOR )
|                                  |
|--[/STOP]--[/OVERLOAD]--[CONVEYOR]+

Overload contact must be in series with the holding path; otherwise the conveyor may restart unsafely.

3. Counting moving objects on conveyor
Photo sensor pulse -> CTU C1
If C1.ACC >= 10 -> turn ON batch complete lamp
Reset push button -> reset C1
4. Fluid level control
Low level switch ON  -> Pump ON
High level switch ON -> Pump OFF
Dry run input       -> Pump OFF and Alarm ON
5. Traffic signal system
Green timer 10 s -> Yellow timer 3 s -> Red timer 10 s -> Repeat
Interlock: opposite direction green cannot be ON at same time.

PLC mistakes that fail in real industry

  • No emergency stop/fault input in ladder.
  • Using only timer without feedback confirmation.
  • Allowing motor forward and reverse outputs together.
  • Not resetting counters/timers during mode change.
  • No manual/auto separation.
  • Ignoring sensor bounce and noise.

Important formulas and memory points

Power devices

MOSFET conduction loss = I²RDS(on)
Gate drive power is related to gate charge and switching frequency.
SCR turn-off requires IA < IH for turn-off time.

Converters

Half-wave controlled rectifier: Vavg = (Vm/2π)(1+cosα)
Full controlled bridge: Vavg = (2Vm/π)cosα
Step-down chopper: Vo = D Vs
Step-up chopper: Vo = Vs/(1-D)

PLC scan memory

Read input → execute logic → update output. Do not assume output changes before the PLC reaches output scan unless the PLC/software supports immediate output instructions.
