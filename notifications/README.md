# Notifications

Notification system configuration and message templates.

## Contents

This directory contains configuration and templates for the site's notification and announcement system. Notifications can appear as:

- Visitor popups (via `assets/js/visitor-popup.js`)
- In-page banners
- Toast notifications

## Relationship to Popups

The visitor popup system (`assets/js/visitor-popup.js`) reads popup media from `/assets/popup/`. Notification configuration in this directory may define additional notification rules or message templates.
