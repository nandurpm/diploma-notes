# Course Code 1004 Mock Examination Structure

The online mock examination follows the uploaded Revision 2021 model-question-paper structure:

- Duration: 3 hours
- Maximum marks: 75
- Part A: answer all 9 one-mark questions (9 marks)
- Part B: answer any 8 of 10 three-mark questions (24 marks)
- Part C: answer one question from each of 6 OR pairs, 7 marks each (42 marks)

Total required responses: 23.
