# Images

Root-level image assets used across the site.

## Contents

| File | Purpose |
|------|---------|
| `guide/*` | Screenshot images for the user guide / how-to pages |
| Root images | Site-level images (hero banners, promotional images) |

## Note

Most images are now stored in `assets/media/` which is the primary image directory. This root `images/` directory contains legacy images and the guide screenshots.
