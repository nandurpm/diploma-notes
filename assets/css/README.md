# CSS Assets

Stylesheets for the POLY PMNA portal, organized by scope and purpose.

## Global Styles

| File | Purpose |
|------|---------|
| `style.css` | Primary site stylesheet. Defines layout, typography, colours, and responsive breakpoints for all portal pages. |
| `theme.css` | Colour theme definitions (light/dark mode, CSS custom properties). |
| `animations.css` | Shared CSS animations and transitions. |
| `responsive.css` | Responsive layout adjustments for mobile, tablet, and desktop breakpoints. |

## Header and Navigation

| File | Purpose |
|------|---------|
| `mobile-header-hotfix.css` | Fixes mobile header rendering issues on certain devices. Loaded by `main.js`. |

## Lesson Pages

| File | Purpose |
|------|---------|
| `lesson-page-fix.css` | Critical layout fixes for lesson pages (full-width, no header gap). Loaded by `lesson-navigation-fix.js`. |
| `lesson-watermark.css` | Semi-transparent brand watermark overlay on lesson content. Loaded on all lesson pages. |

## Site Assistant

| File | Purpose |
|------|---------|
| `site-assistant.css` | Styles for the floating AI assistant panel. |
| `site-assistant-fix.css` | Compatibility fixes for the assistant panel across browsers. |

## Revision 2026

| File | Purpose |
|------|---------|
| `revision-2026-department-themes.css` | Department-specific colour gradients and visual themes. |
| `revision-2026-directory.css` | Layout styles for the department directory grid. |
| `revision-2026-subject.css` | Subject card and semester section styles. |

## Revision 2021

| File | Purpose |
|------|---------|
| `revision-2021-department.css` | Department page styles for Revision 2021. |

## Quiz / Mock Exams

| File | Purpose |
|------|---------|
| `mock-exam.css` | Mock exam interface styles (question cards, answer panels, progress). |
| `daily-quiz.css` | Daily quiz portal styles. |
| `quiz-portal.css` | Quiz portal landing page styles. |

## Components

| File | Purpose |
|------|---------|
| `popup.css` | Visitor popup dialog styles. |
| `maintenance.css` | Maintenance page styles. |
| `tools.css` | Tools page styles. |
| `about.css` | About page styles. |
| `contact.css` | Contact/help page styles. |

## Vendor

| File | Purpose |
|------|---------|
