# Icons

UI icons used throughout the POLY PMNA portal interface.

## Contents

Icon files in SVG, PNG, or ICO format used for:

- Navigation items
- Tool icons
- Department icons
- Status indicators

## Guidelines

- Prefer SVG format for scalability
- Use consistent sizing (24x24 or 48x48 pixels)
- Follow the site's colour palette for icon colours
