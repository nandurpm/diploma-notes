Debugging Handbook

Common mistakes and corrections

MistakeWhy it failsCorrection
if (x = 5)Assignment, not comparison.Use if (x == 5).
Missing & in numeric scanfscanf needs an address.scanf("%d", &x) and check return value.
Array index equals sizeOut-of-bounds access.Loop while i < size.
Binary search on unsorted inputOrdering assumption is violated.Sort first or use linear search.
String without '\0'String functions read beyond intended data.Reserve and preserve terminator space.
Dereferencing NULL/uninitialized pointerNo valid target object.Initialize, validate, then dereference.
Overwriting pointer with failed reallocOriginal block address is lost.Use a temporary pointer.
Reading inactive union memberStored representation may not match.Track active member with an enum tag.
while (!feof(file))EOF is set only after a failed read.Loop on the input function’s return value.
Forgetting fclose or freeResource leak or incomplete output.Release every successfully acquired resource.
