# Revision 2026 downloadable notes PDFs

Add Revision 2026 PDF notes here using this exact filename format:

`downloadable-notes-[SUBJECT_CODE].pdf`

Examples:

- `downloadable-notes-1001.pdf`
- `downloadable-notes-2001C.pdf`
- `downloadable-notes-6031P.pdf`
- `downloadable-notes-6031T.pdf`
- `downloadable-notes-6033D.pdf`

The PDF must correspond to the Revision 2026 lesson and official subject code. It must not be copied from the Revision 2021 `/notes/` folder.

Only valid PDFs above the repository minimum-size check are published as downloadable notes. If a matching lesson HTML exists but this PDF is missing, the website opens that Revision 2026 lesson in print/PDF mode and the PDF workflow can generate the missing file automatically.
