Module I: Complex Numbers

⏱ 15 hrs CO1 Apply

Complex numbers extend the real number system to solve equations like x² + 1 = 0. They are essential in AC circuit analysis, signal processing, and control systems.

The Complex Number System

A complex number is defined as z = x + i y, where x and y are real numbers, and i is the imaginary unit with the property i² = −1.

  • Real part: Re(z) = x
  • Imaginary part: Im(z) = y
Malayalam support: Complex number-നെ z = x + i y എന്ന് എഴുതാം. x ആണ് real ഭാഗം, y ആണ് imaginary ഭാഗം. i എന്നത് √(−1) ആണ്.
Example: For z = 4 − 3i, Re(z) = 4, Im(z) = −3.
Conjugate and Equality

Conjugate: The conjugate of z = x + i y is denoted by z̄ = x − i y.

Equality: Two complex numbers z₁ = x₁ + i y₁ and z₂ = x₂ + i y₂ are equal iff x₁ = x₂ and y₁ = y₂.

Example: If 2x + 3i = 6 − i y, then 2x = 6 ⇒ x = 3, and 3 = −y ⇒ y = −3.
Fundamental Operations
  • Addition: (x₁ + i y₁) + (x₂ + i y₂) = (x₁ + x₂) + i(y₁ + y₂)
  • Subtraction: (x₁ + i y₁) − (x₂ + i y₂) = (x₁ − x₂) + i(y₁ − y₂)
  • Multiplication: (x₁ + i y₁)(x₂ + i y₂) = (x₁x₂ − y₁y₂) + i(x₁y₂ + y₁x₂)
  • Division: (1+i)/(1−i) = ((1+i)(1+i))/(1²+1²) = i (by multiplying numerator and denominator by conjugate of denominator)
Example (Division): Evaluate (2 + 3i) / (1 − i). Multiply by (1 + i): [(2+3i)(1+i)] / (1²+1²) = [(2 − 3) + (2+3)i] / 2 = (−1 + 5i) / 2 = −0.5 + 2.5i.
Graphical Representation (Argand Plane)

The Argand plane is a 2D coordinate system where the x-axis represents the real part and the y-axis represents the imaginary part. Each complex number z = x + i y corresponds to a point (x, y).

Modulus and Amplitude
|z| = r = √(x² + y²)Modulus (Absolute value)
arg(z) = θ = tan⁻¹(y/x)Amplitude (Argument) in degrees

Note: The amplitude is measured from the positive real axis, counterclockwise. For points in different quadrants, add 180° or 360° as needed to get the principal value.

Example: For z = 3 + 4i:
r = √(3² + 4²) = 5
θ = tan⁻¹(4/3) ≈ 53.13° (since both x and y are positive, angle is in QI).

Polar Form

A complex number can be expressed in polar form as:

z = r (cos θ + i sin θ)where r = |z| and θ = arg(z)

This form is particularly useful for multiplication and division of complex numbers.

Example: Write z = 1 + i in polar form.
r = √(1² + 1²) = √2, θ = tan⁻¹(1/1) = 45°.
Polar form: √2 (cos 45° + i sin 45°).
📝 Module I Summary: You've learned to represent, manipulate, and visualize complex numbers. These tools are foundational for AC circuit analysis (impedance) and signal processing.

Module II: Vector Algebra

⏱ 15 hrs CO2 Apply

Vectors describe quantities with both magnitude and direction—essential in mechanics, electromagnetism, and structural analysis.

Scalars, Vectors, and Unit Vectors
  • Scalar: A quantity with only magnitude (e.g., mass, speed, temperature).
  • Vector: A quantity with both magnitude and direction (e.g., force, velocity, displacement).
  • Unit vectors: Vectors with magnitude 1, denoted by i, j, k along the x, y, and z axes respectively.
  • Position vector: A vector representing a point's position relative to the origin: r = x i + y j + z k.
Example: Position vector of point P(2, −3, 1) is r = 2i − 3j + 1k. Magnitude |r| = √(2² + (−3)² + 1²) = √14.
Vector Operations
  • Addition: a + b = (a₁ + b₁)i + (a₂ + b₂)j + (a₃ + b₃)k
  • Subtraction: a − b = (a₁ − b₁)i + (a₂ − b₂)j + (a₃ − b₃)k
  • Scalar multiplication: c a = (c a₁)i + (c a₂)j + (c a₃)k
Dot Product (Scalar Product)
a · b = |a| |b| cos θ = a₁b₁ + a₂b₂ + a₃b₃
  • Used to find the angle between two vectors: cos θ = (a · b) / (|a| |b|)
  • Vectors are perpendicular (orthogonal) if a · b = 0.
Example: Find the angle between a = 2i + 3j − k and b = i − 2j + 2k.
a · b = (2)(1) + (3)(−2) + (−1)(2) = 2 − 6 − 2 = −6.
|a| = √(4+9+1) = √14, |b| = √(1+4+4) = 3.
cos θ = −6 / (3√14) ≈ −0.5345 → θ ≈ 122.3°.
Cross Product (Vector Product)
a × b = (a₂b₃ − a₃b₂)i − (a₁b₃ − a₃b₁)j + (a₁b₂ − a₂b₁)k
  • The result is a vector perpendicular to both a and b.
  • Magnitude |a × b| = |a| |b| sin θ.
  • Vectors are parallel if a × b = 0.
Example: For a = i + 2j + 3k and b = 2i − j + k:
a × b = (2·1 − 3·(−1))i − (1·1 − 3·2)j + (1·(−1) − 2·2)k = 5i + 5j − 5k.
Engineering Applications
  • Area of parallelogram: |a × b|
  • Area of triangle: ½ |a × b|
  • Work done: F · d (dot product of force and displacement)
  • Moment of a force: r × F (cross product of position vector and force)
Example (Work): A force F = 2i + 4j N displaces an object by d = 3i − j m. Work done = F · d = 2·3 + 4·(−1) = 6 − 4 = 2 J.

Module III: Integral Calculus & Differential Equations

⏱ 15 hrs CO3 Apply

Integration is the reverse of differentiation; differential equations model dynamic systems. Together they form the core of engineering mathematics.

Integration as Reverse of Differentiation

Integration undoes differentiation. If d/dx [F(x)] = f(x), then ∫ f(x) dx = F(x) + C, where C is the constant of integration.

Standard Integrals
∫ xⁿ dx = xⁿ⁺¹/(n+1) + Cn ≠ −1
∫ eˣ dx = eˣ + C
∫ 1/x dx = ln|x| + C
∫ sin x dx = −cos x + C
∫ cos x dx = sin x + C
∫ sec² x dx = tan x + C
Integration Techniques
  • Constant multiple rule: ∫ c f(x) dx = c ∫ f(x) dx
  • Sum/Difference rule: ∫ [f(x) ± g(x)] dx = ∫ f(x) dx ± ∫ g(x) dx
  • Substitution:
    • ∫ f(ax + b) dx : let u = ax + b, du = a dx.
    • ∫ f'(x) f(x) dx : let u = f(x), du = f'(x) dx.
    • ∫ f'(x) / f(x) dx = ln|f(x)| + C.
  • Integration by parts: ∫ u dv = uv − ∫ v du
Example (Substitution): ∫ (2x + 1)³ dx.
Let u = 2x + 1, du = 2 dx ⇒ dx = du/2.
∫ u³ du/2 = ½ · u⁴/4 + C = u⁴/8 + C = (2x + 1)⁴/8 + C.
Example (Parts): ∫ x eˣ dx.
Let u = x, dv = eˣ dx ⇒ du = dx, v = eˣ.
∫ x eˣ dx = x eˣ − ∫ eˣ dx = x eˣ − eˣ + C.
Definite Integrals

The definite integral ∫ab f(x) dx gives the net area under the curve from x = a to x = b. Evaluated as F(b) − F(a), where F is the antiderivative.

Example: ∫12 (3x² + 2x) dx.
Antiderivative: x³ + x².
At x = 2: 8 + 4 = 12. At x = 1: 1 + 1 = 2. Result = 12 − 2 = 10.
Differential Equations
  • Order: The highest derivative in the equation.
  • Degree: The power of the highest derivative (when the equation is a polynomial in derivatives).
  • Variable Separable: dy/dx = f(x) g(y) → ∫ 1/g(y) dy = ∫ f(x) dx.
  • Linear First Order: dy/dx + P(x)y = Q(x).
    Integrating factor: IF = e^(∫ P dx).
    Solution: y · IF = ∫ Q · IF dx + C.
Example (Separable): dy/dx = x² / y.
y dy = x² dx → ∫ y dy = ∫ x² dx → y²/2 = x³/3 + C.
Example (Linear): dy/dx + 2y = eˣ.
P = 2, Q = eˣ. IF = e^(∫ 2 dx) = e²ˣ.
y e²ˣ = ∫ eˣ e²ˣ dx = ∫ e³ˣ dx = e³ˣ/3 + C.
y = eˣ/3 + C e⁻²ˣ.

Module IV: Statistics

⏱ 15 hrs CO4 Apply

Statistics helps engineers make sense of data, from quality control to process optimization and decision-making.

Data Collection and Classification
  • Primary data: Collected by the researcher (e.g., surveys, experiments).
  • Secondary data: Already collected by others (e.g., government records, company reports).
  • Qualitative data: Categorical (e.g., color, type).
  • Quantitative data: Numerical (e.g., weight, temperature).
  • Raw data: Unprocessed data. Array: Organized in ascending/descending order.
  • Frequency distribution: A table showing how often each value or class occurs.
Frequency Distribution & Graphical Representation
  • Class intervals: Ranges (e.g., 0–10). Class limits: The endpoints. Class boundaries: Midpoints between upper limit of one class and lower limit of next (e.g., 0–10 becomes −0.5 to 10.5).
  • Histogram: Bar chart of class intervals vs. frequencies.
  • Frequency polygon: Line graph connecting midpoints of class tops.
  • Ogive (Cumulative frequency curve): Plot of cumulative frequency against upper class boundaries.
Measures of Central Tendency
  • Arithmetic Mean: Sum of values / number of values. For grouped data: x̄ = (Σ f m) / Σ f, where m is the midpoint.
  • Median: Middle value. For grouped data: Median = L + [(n/2 − cf) / f] × h.
  • Mode: Most frequent value. For grouped data: Mode = L + [(f₁ − f₀) / (2f₁ − f₀ − f₂)] × h.
Example (Ungrouped Mean): Data: 2, 4, 6, 8, 10. Mean = (2+4+6+8+10)/5 = 30/5 = 6.
Measures of Dispersion
  • Mean Deviation: Average of absolute deviations from the mean.
  • Variance (σ²): Average of squared deviations from the mean. For grouped data: σ² = [Σ f (m − x̄)²] / Σ f.
  • Standard Deviation (σ): Square root of variance.
Example (Ungrouped SD): Data: 2, 4, 6, 8, 10. Mean = 6.
Deviations: (−4)² + (−2)² + 0² + 2² + 4² = 16+4+0+4+16 = 40.
Variance = 40/5 = 8. Standard Deviation = √8 ≈ 2.83.

Practice Module-wise Questions & Answers

Module I: Complex Numbers

Q1: Find the conjugate and modulus of z = 5 − 12i.
Conjugate z̄ = 5 + 12i. Modulus |z| = √(5² + (−12)²) = √(25+144) = √169 = 13.
Q2: Express z = 1 + √3 i in polar form.
r = √(1+3) = 2. θ = tan⁻¹(√3/1) = 60°. Polar form: 2(cos 60° + i sin 60°).
Q3: If (2+3i)(x+iy) = 1+i, find x and y.
(2x−3y) + (2y+3x)i = 1+i. Equate: 2x−3y=1, 3x+2y=1. Solve: multiply first by 2: 4x−6y=2; second by 3: 9x+6y=3. Add: 13x=5 ⇒ x=5/13. Then 2(5/13)−3y=1 ⇒ 10/13−3y=1 ⇒ −3y=3/13 ⇒ y=−1/13.

Module II: Vector Algebra

Q1: Find the unit vector in the direction of a = 2i − 3j + 6k.
|a| = √(4+9+36) = 7. Unit vector = (2/7)i − (3/7)j + (6/7)k.
Q2: Find the angle between a = i + 2j − k and b = 2i − j + 2k.
Dot = 1·2 + 2·(−1) + (−1)·2 = 2−2−2 = −2. |a| = √6, |b| = 3. cos θ = −2/(3√6) ⇒ θ ≈ 105.8°.
Q3: Compute a × b where a = 2i + 3j + 4k, b = i − 2j + k.
(3·1 − 4·(−2))i − (2·1 − 4·1)j + (2·(−2) − 3·1)k = 11i + 2j − 7k.

Module III: Integral Calculus & DEs

Q1: Evaluate ∫ (3x² + 2x + 1) dx.
= x³ + x² + x + C.
Q2: Evaluate ∫01 e²ˣ dx.
Antiderivative = ½ e²ˣ. At 1: ½ e²; at 0: ½. Result = ½(e² − 1).
Q3: Solve dy/dx = 3x² y.
Separate: dy/y = 3x² dx. Integrate: ln|y| = x³ + C ⇒ y = A e^(x³).

Module IV: Statistics

Q1: Calculate the mean of the data: 10, 12, 14, 16, 18.
Sum = 70, n = 5, Mean = 14.
Q2: Find the median of: 5, 8, 12, 15, 20, 25.
n=6 (even). Median = average of 3rd and 4th values = (12+15)/2 = 13.5.
Q3: Compute standard deviation for: 2, 4, 6, 8, 10.
Mean = 6. Deviations: (−4)² + (−2)² + 0² + 2² + 4² = 40. Variance = 40/5 = 8. SD = √8 ≈ 2.83.

  • Mode: L + [(f₁−f₀)/(2f₁−f₀−f₂)]×h
  • SD: √[Σf(m−x̄)²/Σf]
  • Common mistake: using wrong class boundaries or midpoints
