Module I

Complex Numbers

14 hours (L:10 + T:4) CO1 Bloom: Apply

🎯 Learning Goals

  • Understand the complex number system
  • Perform fundamental operations
  • Represent complex numbers graphically
  • Find modulus, amplitude, and polar form
  • Solve engineering problems

🔑 Key Facts

  • i = √(−1)
  • z = a + ib
  • |z| = √(a² + b²)
  • arg(z) = tan⁻¹(b/a)
  • Polar: z = r(cos θ + i sin θ)
The Complex Number System

A complex number is a number of the form z = a + ib, where a and b are real numbers, and i is the imaginary unit defined by i² = −1.

  • Real part: Re(z) = a
  • Imaginary part: Im(z) = b
z = a + ib  ·  a,b ∈ ℝ  ·  i² = −1

Example: z = 3 + 4i has Re = 3 and Im = 4.

Malayalam support: സങ്കീർണ്ണ സംഖ്യകൾ (complex numbers) എന്നത് a + ib രൂപത്തിലുള്ള സംഖ്യകളാണ്. ഇവിടെ 'i' എന്നത് √(−1) ആണ്. ഇത് ഇലക്ട്രിക്കൽ എഞ്ചിനീയറിംഗിലും സിഗ്നൽ പ്രോസസ്സിംഗിലും വ്യാപകമായി ഉപയോഗിക്കുന്നു.
💡 Tip: The real and imaginary parts are always real numbers. The imaginary part includes the coefficient of i, not i itself.
Conjugate and Equality

Conjugate: The conjugate of z = a + ib is z̄ = a − ib.

z̄ = a − ib

Equality: Two complex numbers z₁ = a₁ + ib₁ and z₂ = a₂ + ib₂ are equal iff a₁ = a₂ and b₁ = b₂.

Example: If 2x + 3iy = 4 + 6i, then 2x = 4 ⇒ x = 2, and 3y = 6 ⇒ y = 2.
💡 Tip: The conjugate is used to rationalise denominators and find modulus.
Fundamental Operations

For z₁ = a + ib and z₂ = c + id:

  • Addition: z₁ + z₂ = (a+c) + i(b+d)
  • Subtraction: z₁ − z₂ = (a−c) + i(b−d)
  • Multiplication: z₁ · z₂ = (ac − bd) + i(ad + bc)
  • Division: z₁ / z₂ = (a+ib)/(c+id) × (c−id)/(c−id) = [(ac+bd) + i(bc−ad)] / (c² + d²)
Example (Multiplication): (2+3i)(1−4i) = 2 − 8i + 3i − 12i² = 2 − 5i + 12 = 14 − 5i
Example (Division): (3+4i)/(1−2i) = (3+4i)(1+2i)/5 = (3+6i+4i+8i²)/5 = (−5+10i)/5 = −1 + 2i
⚠️ Common mistake: In division, always multiply numerator and denominator by the conjugate of the denominator.
Graphical Representation — Argand Plane

Complex numbers are represented on the Argand plane (complex plane) with the real part on the horizontal axis and the imaginary part on the vertical axis.

Malayalam support: Argand plane-ൽ complex numbers-നെ points ആയി represent ചെയ്യുന്നു. Horizontal axis real part-um vertical axis imaginary part-um ആണ്.
Modulus and Amplitude

Modulus (Absolute value): |z| = √(a² + b²). It is the distance from the origin to the point (a, b).

Amplitude (Argument): θ = arg(z) = tan⁻¹(b/a), measured in degrees (or radians).

|z| = √(a² + b²)  ·  θ = tan⁻¹(b/a)
Example: For z = 3 + 4i: |z| = √(9+16) = 5, θ = tan⁻¹(4/3) ≈ 53.13°
⚠️ Common mistake: The argument depends on the quadrant. Always check the signs of a and b. In QII, θ = 180° − tan⁻¹(b/|a|).
Polar Form

A complex number can be expressed in polar form as:

z = r(cos θ + i sin θ)  ·  r = |z|, θ = arg(z)

This is also written as z = r ∠ θ or z = r cis θ.

Example: For z = 3 + 4i: r = 5, θ = 53.13° ⇒ z = 5(cos 53.13° + i sin 53.13°)
💡 Tip: Polar form is especially useful for multiplication and division — multiply moduli and add arguments.
Solved Problems
Problem 1: Find the modulus and argument of z = −1 + i.
Solution: a = −1, b = 1. r = √(1+1) = √2. θ = 180° − tan⁻¹(1/1) = 180° − 45° = 135°.
Problem 2: Express z = 2 − 2i in polar form.
Solution: r = √(4+4) = 2√2. θ = −tan⁻¹(2/2) = −45°. z = 2√2(cos(−45°) + i sin(−45°)).
Problem 3: If z₁ = 1+2i and z₂ = 3−i, find z₁ × z₂.
Solution: (1+2i)(3−i) = 3 − i + 6i − 2i² = 3 + 5i + 2 = 5 + 5i.
💡 Engineering Application: Complex numbers model AC circuits — impedance Z = R + iX, with magnitude giving total opposition and phase angle giving phase shift.

Module II

Probability & Statistics

15 hours (L:12 + T:3) CO2 Bloom: Apply

🎯 Learning Goals

  • Understand sets, random experiments, sample space
  • Apply classical probability axioms
  • Solve problems with coins, dice, cards
  • Organise data and compute mean/median/mode

🔑 Key Facts

  • P(E) = n(E)/n(S)
  • 0 ≤ P(E) ≤ 1
  • Mean = Σx/n
  • Median = middle value (ordered)
  • Mode = most frequent value
Sets: Empty, Universal, Subsets
  • Set: A well-defined collection of objects.
  • Empty set (∅): A set with no elements.
  • Universal set (U): The set containing all elements under consideration.
  • Subset: A ⊆ B if every element of A is also in B.
Example: For rolling a die, U = {1,2,3,4,5,6}, A = {2,4,6} (even numbers) is a subset of U.
Malayalam support: Set എന്നത് നിർവചിക്കപ്പെട്ട വസ്തുക്കളുടെ ശേഖരമാണ്. Empty set-ന് ഒരു ഘടകവുമില്ല. Universal set-ൽ എല്ലാ ഘടകങ്ങളും ഉൾപ്പെടും.
Random Experiments, Outcomes, Sample Space
  • Random experiment: An experiment whose outcome is not certain.
  • Outcome: A single result of an experiment.
  • Sample space (S): The set of all possible outcomes.
  • Event (E): A subset of the sample space.
Example: Tossing a coin: S = {H, T}. Event E = {H} (getting heads).
Classical Definition & Axioms of Probability

Classical definition: For a random experiment with n(S) equally likely outcomes, the probability of event E is:

P(E) = n(E) / n(S)

Axioms:

  • 0 ≤ P(E) ≤ 1
  • P(S) = 1
  • For mutually exclusive events, P(E₁ ∪ E₂) = P(E₁) + P(E₂)
💡 Tip: The sum of probabilities of all outcomes in S is 1.
Problems: Coins, Die, Cards
Coin (1 coin): S = {H, T}. P(H) = 1/2.
Coin (2 coins): S = {HH, HT, TH, TT}. P(HT) = 1/4, P(at least one H) = 3/4.
Die: S = {1,2,3,4,5,6}. P(even) = 3/6 = 1/2.
Cards: From a deck of 52, P(heart) = 13/52 = 1/4.
⚠️ Common mistake: In "at least one" problems, use the complement rule: P(at least one) = 1 − P(none).
Introduction to Statistics

Statistics: The science of collecting, organising, analysing, and interpreting data.

  • Ungrouped data: Raw data as collected.
  • Frequency distribution: A table showing how often each value occurs.
Example: Marks: 5,7,7,8,9. Frequency: 5→1, 7→2, 8→1, 9→1.
Measures of Central Tendency

Mean (x̄): Sum of all values ÷ number of values.

x̄ = Σx / n

Median: The middle value when data is ordered (or average of two middle values if n is even).

Mode: The value that occurs most frequently.

Example: Data: 3, 5, 7, 7, 9. Mean = 31/5 = 6.2. Median = 7. Mode = 7.
Example (even n): 2, 4, 6, 8. Median = (4+6)/2 = 5.
💡 Tip: Mean is affected by outliers; median and mode are more robust.
Frequency Distribution — Mean, Median, Mode

For grouped frequency distribution:

x̄ = Σ(f·x) / Σf

Median for grouped data: find the class containing (n+1)/2-th observation.

Mode for grouped data: the class with highest frequency.

Example: x: 1,2,3,4   f: 2,3,1,2. Σf = 8. Σ(f·x) = 2+6+3+8 = 19. x̄ = 19/8 = 2.375.
Malayalam support: Frequency distribution-ൽ data-യെ groups ആക്കി തിരിച്ച് അവയുടെ frequencies കണക്കാക്കുന്നു. Mean, median, mode എന്നിവ central tendency-യുടെ measures ആണ്.

Module III

Integral Calculus

15 hours (L:11 + T:4) CO3 Bloom: Apply

🎯 Learning Goals

  • Understand integration as reverse of differentiation
  • Recall standard integrals
  • Apply substitution and integration by parts
  • Evaluate definite integrals
  • Solve first-order differential equations

🔑 Key Facts

  • ∫ xⁿ dx = xⁿ⁺¹/(n+1) + C (n≠−1)
  • ∫ eˣ dx = eˣ + C
  • ∫ 1/x dx = ln|x| + C
  • ∫ sin x dx = −cos x + C
  • ∫ cos x dx = sin x + C
Integration as Reverse of Differentiation

Integration is the inverse process of differentiation. If d/dx [F(x)] = f(x), then ∫ f(x) dx = F(x) + C, where C is the constant of integration.

∫ f(x) dx = F(x) + C  ·  d/dx [F(x)] = f(x)
Example: d/dx (x²) = 2x ⇒ ∫ 2x dx = x² + C.
💡 Tip: The constant C accounts for all antiderivatives. Always include it in indefinite integrals.
Standard Integrals
∫ xⁿ dx = xⁿ⁺¹/(n+1) + C
n ≠ −1
∫ 1/x dx = ln|x| + C
x ≠ 0
∫ eˣ dx = eˣ + C
∫ sin x dx = −cos x + C
∫ cos x dx = sin x + C
∫ sec² x dx = tan x + C
∫ cosec² x dx = −cot x + C
∫ sec x tan x dx = sec x + C
∫ cosec x cot x dx = −cosec x + C
Rules of Integration & Substitution

Rules:

  • ∫ k·f(x) dx = k·∫ f(x) dx
  • ∫ [f(x) ± g(x)] dx = ∫ f(x) dx ± ∫ g(x) dx

Substitution:

  • ∫ f(ax+b) dx = (1/a) F(ax+b) + C
  • ∫ f(x)·f'(x) dx = [f(x)]²/2 + C
  • ∫ f'(x)/f(x) dx = ln|f(x)| + C
Example (substitution): ∫ (2x+3)⁵ dx. Let u = 2x+3, du = 2dx ⇒ dx = du/2. = 1/2 ∫ u⁵ du = u⁶/12 + C = (2x+3)⁶/12 + C.
Example (f'/f): ∫ (2x)/(x²+1) dx = ln|x²+1| + C.
Integration by Parts

For product of two functions:

∫ u dv = uv − ∫ v du

LIATE rule (choose u as the function that comes first): Logarithmic, Inverse trigonometric, Algebraic, Trigonometric, Exponential.

Example: ∫ x sin x dx. Let u = x (algebraic), dv = sin x dx ⇒ du = dx, v = −cos x. = x(−cos x) − ∫ (−cos x) dx = −x cos x + sin x + C.
⚠️ Common mistake: Choosing the wrong u can make the integral more complex. Use LIATE.
Definite Integrals

A definite integral has limits of integration:

∫ₐᵇ f(x) dx = [F(x)]ₐᵇ = F(b) − F(a)
Example: ∫₀¹ x² dx = [x³/3]₀¹ = 1/3 − 0 = 1/3.
Example (area): Area bounded by y = x², x-axis, x=0, x=2 is ∫₀² x² dx = [x³/3]₀² = 8/3 sq. units.
💡 Engineering Application: Definite integrals compute areas, volumes, work done, and centre of mass.
Differential Equations

Order: The highest derivative present.

Degree: The exponent of the highest derivative (after removing radicals).

Example: d²y/dx² + 3(dy/dx) + 2y = 0 → Order 2, Degree 1.

Variable separable: dy/dx = f(x)g(y) ⇒ ∫ dy/g(y) = ∫ f(x) dx.

Example: dy/dx = xy ⇒ dy/y = x dx ⇒ ln|y| = x²/2 + C ⇒ y = C e^(x²/2).

Linear first-order: dy/dx + P(x)y = Q(x).

Integrating factor: I.F. = e^(∫ P dx)  ·  y·I.F. = ∫ Q·I.F. dx + C
Example: dy/dx + 2y = x. P = 2, I.F. = e^(∫2 dx) = e^(2x). y e^(2x) = ∫ x e^(2x) dx + C. Solve to get y = (2x−1)/4 + C e^(−2x).

Module IV

Numerical Methods & Vector Algebra

16 hours (L:12 + T:4) CO4 Bloom: Apply

🎯 Learning Goals

  • Understand interpolation and Lagrange's method
  • Apply Simpson's 1/3rd rule
  • Distinguish scalars and vectors
  • Compute dot and cross products
  • Find magnitude and unit vectors

🔑 Key Facts

  • Lagrange interpolation: L(x) = Σ yᵢ · ℓᵢ(x)
  • Simpson's 1/3rd: ∫ₐᵇ f(x)dx ≈ h/3 [f₀ + fₙ + 4Σodd + 2Σeven]
  • a·b = |a||b| cos θ
  • a×b = |a||b| sin θ · n̂
Interpolation & Lagrange's Method

Interpolation is the process of estimating unknown values between known data points.

Lagrange's method constructs a polynomial that passes through all given points:

L(x) = Σᵢ₌₀ⁿ yᵢ · ℓᵢ(x), where ℓᵢ(x) = Πⱼ₌₀,ⱼ≠ᵢⁿ (x − xⱼ)/(xᵢ − xⱼ)
Example: Given (1,2), (2,3), (3,5). Find y at x=2.5.
ℓ₀ = (x−2)(x−3)/((1−2)(1−3)) = (x−2)(x−3)/2
ℓ₁ = (x−1)(x−3)/((2−1)(2−3)) = −(x−1)(x−3)
ℓ₂ = (x−1)(x−2)/((3−1)(3−2)) = (x−1)(x−2)/2
L(2.5) = 2·ℓ₀ + 3·ℓ₁ + 5·ℓ₂. Compute: ℓ₀ = (0.5)(−0.5)/2 = −0.125, ℓ₁ = −(1.5)(−0.5) = 0.75, ℓ₂ = (1.5)(0.5)/2 = 0.375. L = 2(−0.125)+3(0.75)+5(0.375) = −0.25+2.25+1.875 = 3.875.
💡 Tip: Lagrange's method avoids solving systems of equations but can be computationally intensive for large n.
Numerical Integration — Simpson's 1/3rd Rule

For approximating ∫ₐᵇ f(x) dx with n even subintervals of width h = (b−a)/n:

∫ₐᵇ f(x) dx ≈ (h/3) [f₀ + fₙ + 4(f₁ + f₃ + ... + fₙ₋₁) + 2(f₂ + f₄ + ... + fₙ₋₂)]
Example: Approximate ∫₀² x² dx using n=4. h = 0.5. f₀=0, f₁=0.25, f₂=1, f₃=2.25, f₄=4. ≈ (0.5/3)[0+4 + 4(0.25+2.25) + 2(1)] = (1/6)[4 + 4(2.5) + 2] = (1/6)[4+10+2] = 16/6 = 2.6667. Exact: 8/3 = 2.6667.
⚠️ Common mistake: n must be even for Simpson's 1/3rd rule. If n is odd, use Simpson's 3/8th rule or composite methods.
Scalars and Vectors
  • Scalar: A quantity with only magnitude (e.g., mass, temperature).
  • Vector: A quantity with both magnitude and direction (e.g., velocity, force).

Unit vectors: î, ĵ, k̂ along x, y, z axes.

Position vector: r = x î + y ĵ + z k̂.

Malayalam support: Scalar-ന് magnitude മാത്രമേ ഉള്ളൂ (ഉദാ: mass). Vector-ന് magnitude-ഉം direction-ഉം ഉണ്ട് (ഉദാ: velocity). Unit vectors î, ĵ, k̂ axes-നെ സൂചിപ്പിക്കുന്നു.
Magnitude and Unit Vector

Magnitude: |v| = √(x² + y² + z²) for v = x î + y ĵ + z k̂.

Unit vector: v̂ = v / |v| (direction of v).

Example: v = 3î + 4ĵ. |v| = 5. v̂ = (3/5)î + (4/5)ĵ.
Vector Addition, Subtraction, Scalar Multiplication
  • Addition: v + w = (v₁+w₁)î + (v₂+w₂)ĵ + (v₃+w₃)k̂
  • Subtraction: v − w = (v₁−w₁)î + (v₂−w₂)ĵ + (v₃−w₃)k̂
  • Scalar multiplication: c·v = (c v₁)î + (c v₂)ĵ + (c v₃)k̂
Example: v = 2î+3ĵ, w = 1î−2ĵ. v+w = 3î+1ĵ, v−w = 1î+5ĵ, 3v = 6î+9ĵ.
Dot Product
v·w = |v||w| cos θ  ·  v·w = v₁w₁ + v₂w₂ + v₃w₃
  • Angle: cos θ = (v·w)/(|v||w|)
  • Perpendicular: v⊥w ⇔ v·w = 0
Example: v = 2î+3ĵ, w = 1î−2ĵ. v·w = 2(1)+3(−2) = 2−6 = −4. |v|=√13, |w|=√5, cos θ = −4/(√13·√5) ≈ −0.496.
Cross Product
v×w = |v||w| sin θ · n̂  ·  v×w = (v₂w₃−v₃w₂)î − (v₁w₃−v₃w₁)ĵ + (v₁w₂−v₂w₁)k̂
  • Parallel: v ∥ w ⇔ v×w = 0
Example: v = 2î+3ĵ, w = 1î−2ĵ. v×w = (3·0−0·(−2))î − (2·0−0·1)ĵ + (2·(−2)−3·1)k̂ = −7k̂.
💡 Engineering Application: Cross product gives torque (τ = r×F) and is used in magnetism and rotational dynamics.

❓ Module-wise Questions with Answers

Module I — Complex Numbers

Q1: Find the modulus and argument of z = 1 + i.
|z| = √(1²+1²) = √2. θ = tan⁻¹(1/1) = 45°.
Q2: Express z = 2 − 2i in polar form.
r = √(4+4) = 2√2. θ = −45°. z = 2√2(cos(−45°) + i sin(−45°)).
Q3: If z₁ = 1+2i and z₂ = 3−i, find z₁ × z₂.
(1+2i)(3−i) = 3−i+6i−2i² = 3+5i+2 = 5+5i.
Q4: What is the conjugate of 3 − 4i?
Conjugate is 3 + 4i.

Module II — Probability & Statistics

Q1: A coin is tossed twice. Find the probability of getting exactly one head.
S = {HH, HT, TH, TT}. n(S)=4. E = {HT, TH}. n(E)=2. P = 2/4 = 1/2.
Q2: Find the mean of 3, 5, 7, 7, 9.
Mean = (3+5+7+7+9)/5 = 31/5 = 6.2.
Q3: What is the median of 2, 4, 6, 8?
n=4 (even). Median = (4+6)/2 = 5.
Q4: A die is rolled. Find P(prime number).
S = {1,2,3,4,5,6}. Primes = {2,3,5}. P = 3/6 = 1/2.

Module III — Integral Calculus

Q1: Evaluate ∫ 3x² dx.
∫ 3x² dx = 3·(x³/3) + C = x³ + C.
Q2: Evaluate ∫₀¹ x dx.
[x²/2]₀¹ = 1/2 − 0 = 1/2.
Q3: Solve dy/dx = 2x.
dy = 2x dx ⇒ ∫ dy = ∫ 2x dx ⇒ y = x² + C.
Q4: Find the order and degree of d²y/dx² + 3(dy/dx) + 2y = 0.
Order = 2 (highest derivative), Degree = 1 (exponent of highest derivative).

Module IV — Numerical Methods & Vector Algebra

Q1: Given (1,2), (2,3), (3,5), find y at x=2.5 using Lagrange's method.
L(2.5) = 2·ℓ₀ + 3·ℓ₁ + 5·ℓ₂ = 3.875 (as worked in section).
Q2: Approximate ∫₀¹ x² dx using Simpson's 1/3rd with n=2.
h = 0.5. f₀=0, f₁=0.25, f₂=1. ≈ (0.5/3)[0+1+4(0.25)] = (1/6)[1+1] = 1/3 = 0.3333.
Q3: Find the magnitude of v = 3î + 4ĵ.
|v| = √(9+16) = 5.
Q4: Compute the dot product of a = (2,3) and b = (1,−2).
a·b = 2(1)+3(−2) = 2−6 = −4.

⚡ Quick Revision

Module I — Complex Numbers

  • z = a + ib, i² = −1
  • |z| = √(a²+b²), θ = tan⁻¹(b/a)
  • Polar: z = r(cos θ + i sin θ)
  • Operations: add real/imag separately

Module II — Probability & Stats

  • P(E) = n(E)/n(S)
  • Mean = Σx/n, Median = middle, Mode = most frequent
  • Sample space for coins/dice/cards

Module III — Integral Calculus

  • ∫ xⁿ dx = xⁿ⁺¹/(n+1) + C
  • ∫ u dv = uv − ∫ v du
  • Definite: ∫ₐᵇ = F(b)−F(a)
  • D.E.: variable separable & linear

Module IV — Num Methods & Vectors

  • Lagrange: L(x) = Σ yᵢ·ℓᵢ(x)
  • Simpson's: h/3 [f₀+fₙ+4Σodd+2Σeven]
  • a·b = |a||b| cos θ
  • a×b = |a||b| sin θ·n̂

⚠️ Common Mistakes — Exam Checklist

  • ✔️ In complex division, multiply by conjugate of denominator
  • ✔️ In probability, check if order matters (permutations vs combinations)
  • ✔️ In integration, always add +C for indefinite integrals
  • ✔️ In Simpson's rule, n must be even
  • ✔️ In vectors, cross product gives a vector, dot product gives a scalar
  • ✔️ In differential equations, identify order and degree correctly
