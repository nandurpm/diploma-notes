Module 1

Basics of C Programming & Control Statements

C syntax turns a problem-solving plan into a structured executable program.

Official hours: 17 LMapped CO: CO1Bloom level: Understand

Learning goals

  • Identify tokens, data types, variables and operators.
  • Write simple input/output programs.
  • Select decision, iteration and transfer statements.

Key facts

  • C is case-sensitive.
  • A declaration introduces type and name.
  • Choose loop type from the required repetition behavior.

Engineering relevance

Use the concepts to interpret technical information, communicate decisions accurately, and solve appropriately scoped problems.

Character set, tokens, identifiers, keywords, data types and variables

The C character set supplies letters, digits and special symbols. A token is a meaningful lexical unit such as a keyword, identifier, constant, string literal or operator. Identifiers must follow naming rules and keywords cannot be used as user-defined names. Common data types include integer, floating-point, character and void forms.

Malayalam support: C case-sensitive ആണ്: `Total` ഉം `total` ഉം വ്യത്യസ്ത identifiers ആണ്. Variable ഉപയോഗിക്കുന്നതിന് മുമ്പ് declaration ചെയ്യണം.
int count = 0;
float voltage = 12.5f;
char grade = 'A';
Operators, precedence and expressions

Arithmetic, relational, logical, conditional, unary, increment/decrement and assignment operators combine values into expressions. Precedence determines grouping, but parentheses should be used when they improve clarity. Distinguish assignment `=` from equality test `==`.

Given: int a=5, b=2.
Required: Evaluate a/b and a%b.
Calculation: Integer division gives 2; remainder gives 1.
Answer: a/b=2 and a%b=1.
Structure of C programs and printf/scanf

A basic program commonly contains headers, a main() function, declarations, executable statements and a return statement. Use format specifiers that match the variable type. `printf()` displays formatted output; `scanf()` reads input and generally needs the address operator for ordinary variables.

#include <stdio.h>
int main(void){
    int n;
    scanf("%d", &n);
    printf("%d", n);
    return 0;
}
Decision, iterative and control-transfer statements

Use if, if-else, nested if and switch for decisions. Use while when the condition is tested before each iteration, do-while when one execution is required before testing, and for for a compact count-controlled loop. Nested loops are useful for tables and matrices. `break` exits a loop/switch; `continue` skips to the next iteration.

Common mistake: Ensure the loop control variable changes and use braces when more than one statement belongs to a branch.

Module 2

Arrays and Strings

Arrays store related values under one name; strings are character arrays terminated by a null character.

Official hours: 15 LMapped CO: CO2Bloom level: Understand

Learning goals

  • Declare, initialize and access 1D and 2D arrays.
  • Apply arrays to search, sort and matrix representation.
  • Read, display and process strings with library functions.

Key facts

  • C array indices start at 0.
  • Do not access outside bounds.
  • A C string ends with ``.

Engineering relevance

Use the concepts to interpret technical information, communicate decisions accurately, and solve appropriately scoped problems.

Single-dimensional arrays

A one-dimensional array has a fixed element type and contiguous indexed storage. Declare it with a size or initializer, access A[i], and traverse it using a loop. Applications include sum, average, maximum, minimum, linear search and sorting.

int a[5] = {4, 1, 7, 2, 9};
int sum = 0;
for(int i=0;i<5;i++) sum += a[i];
Malayalam support: Array index സാധാരണയായി 0 മുതൽ തുടങ്ങുന്നു. `a[5]` എന്ന declaration-ൽ valid indices 0 മുതൽ 4 വരെയാണ്.
Multidimensional arrays and matrices

A two-dimensional array represents rows and columns, such as a matrix. Use nested loops for initialization, display and matrix addition. Keep row and column limits explicit.

Given: A=[[1,2],[3,4]], B=[[5,6],[7,8]].
Required: A+B.
Calculation: Add corresponding entries.
Answer: [[6,8],[10,12]].
Strings and library functions

Declare a string as a character array with enough space for the terminating null character. The syllabus requires reading, displaying and string-related programs using library functions. Know the purpose and safe use of common functions such as length, copy, concatenate and compare; always consider buffer size and input method.

Module 3

Functions and Structures

Functions divide programs into reusable units, while structures and unions group related data.

Official hours: 15 LMapped CO: CO3Bloom level: Apply

Learning goals

  • Write prototypes, definitions and calls.
  • Distinguish pass by value and passing addresses/reference-style behavior.
  • Use recursion, structures and unions.

Key facts

  • A prototype communicates a function signature.
  • C passes arguments by value; pointers can allow a function to modify caller data.
  • A union shares storage among members.

Engineering relevance

Use the concepts to interpret technical information, communicate decisions accurately, and solve appropriately scoped problems.

Functions and their components

A function definition contains return type, name, parameters and body. A prototype declares the interface before use; a function call transfers control and supplies arguments. Built-in/library functions are provided by headers, while user-defined functions are written by the programmer.

int add(int a, int b);
int add(int a, int b){ return a+b; }
int main(void){ printf("%d", add(2,3)); }
Parameter passing and arrays

Pass by value copies a value, so changing the parameter does not change the caller’s ordinary variable. Passing an address through a pointer allows the called function to update caller storage. Array arguments provide access to the original array elements; document size assumptions.

Recursion

Recursion is a function calling itself on a smaller subproblem. Every recursive solution needs a base case and progress toward that case.

int factorial(int n){
    if(n<=1) return 1;
    return n*factorial(n-1);
}

Structures and unions

A structure groups members of possibly different types and gives each member separate storage. Access members with the dot operator, or arrow through a pointer. A union declares different members sharing the same memory area; only the currently meaningful member should be read. The syllabus requires definition, declaration, member access and structure–union comparison.

Module 4

Pointers and File Handling

Pointers expose addresses and enable indirect access, while files preserve data beyond one program execution.

Official hours: 13 LMapped CO: CO4Bloom level: Apply

Learning goals

  • Declare and safely dereference pointers.
  • Pass pointers to functions.
  • Open, read, write and close text files using modes.

Key facts

  • Initialize pointers before dereferencing.
  • Check file-open failure.
  • Always close an opened file.

Engineering relevance

Use the concepts to interpret technical information, communicate decisions accurately, and solve appropriately scoped problems.

Pointers and pointer parameters

A pointer stores the address of an object. `&x` obtains an address and `*p` dereferences it. Passing a pointer to a function permits indirect modification of caller data and is central to swap and array-processing programs.

void swap(int *a,int *b){
    int t=*a; *a=*b; *b=t;
}
Safety: Never dereference an uninitialized, null or invalid pointer; do not return the address of a local object that no longer exists.
Files, modes and operations

A file is a named stream of stored data. Use a FILE* file pointer with fopen(), perform reading or writing, and call fclose(). The required modes are r, w, a, r+, w+ and a+. Understand that write mode can truncate an existing file.

Basic C file modes
ModePurpose
rRead existing file
wWrite; create or truncate
aAppend; create if needed
r+Read and write existing file
w+Read/write; create or truncate
a+Read and append; create if needed
Opening, reading, writing, closing and troubleshooting

Check the return value of fopen() before use. Use appropriate formatted or character/block operations for the file content. A complete solution handles errors, performs the requested operation and closes the file. Common errors include wrong mode, missing fclose(), using a file pointer before opening and confusing a file pointer with an ordinary data pointer.

FILE *fp = fopen("notes.txt","w");
if(fp == NULL) return 1;
fprintf(fp,"Hello\n");
fclose(fp);

Module-wise question bank

Questions and answers

Answers are deliberately matched to the likely mark value: definitions are concise, while longer answers use structure, comparison, formulae or diagrams.

Module I — C basics

What is a token?
A token is a meaningful lexical unit such as a keyword, identifier, constant, string literal or operator.
Differentiate = and ==.
`=` assigns a value; `==` tests equality.
When is a do-while loop useful?
When the loop body must execute at least once before the condition is tested.

Module II — Arrays and strings

What is an array?
An array is a collection of same-type elements stored under one name and accessed by index.
Why does a C string need a null character?
The null character marks the end of the character sequence for string functions.
Name two array applications in the syllabus.
Searching and sorting; matrix representation is another.

Module III — Functions and structures

What is a function prototype?
A declaration that specifies a function’s name, return type and parameter types before a call or definition.
What is recursion?
A function-solving technique in which a function calls itself with a smaller subproblem and a base case.
Give one difference between structure and union.
Structure members have separate storage; union members share storage.

Module IV — pointers and files

What is a pointer?
A variable that stores the address of another object.
Why check fopen() result?
It returns NULL when the file cannot be opened; using it without checking can cause failure.
Why is fclose() required?
It releases the file resource and ensures buffered output is flushed.
