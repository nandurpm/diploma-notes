## 2026-07-23 - [Calculator Form Enter Submission and CLS Optimization]
**Learning:** In dynamically generated single-page forms with more than one input field, pressing Enter does not trigger standard `onsubmit` events if there is no native submit button. Standard browser behavior restricts Enter-key submission to single-input forms. To resolve this, listening to `keydown` for "Enter" on the form element and triggering the calculation action is an elegant, robust workaround. Additionally, pre-populating dynamic badges statically in the HTML avoids high Cumulative Layout Shift (CLS) on slow networks.
**Action:** Always capture `onkeydown` for "Enter" on multi-input dynamic forms without submit buttons to allow intuitive keyboard submission, and render static placeholders for dynamic badges to protect CLS budget.
