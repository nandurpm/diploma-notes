# .well-known

Standard web well-known files for domain verification and service discovery.

## Contents

| File | Purpose |
|------|---------|
| `security.txt` | Security contact information and vulnerability disclosure policy |

## Purpose

The `.well-known` directory follows RFC 5785 conventions. Files here are served at the root of the domain (e.g., `https://pmna.dpdns.org/.well-known/security.txt`) and are used by browsers, search engines, and security tools.
