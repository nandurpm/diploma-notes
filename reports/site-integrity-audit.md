# Site Integrity Audit

> **The former 73-page / 17-lesson “all checks passed” result has been retired. It did not cover the current Revision 2026 architecture and must not be used as release evidence.**

The current audit is generated by:

```bash
python tools/audit_site.py
```

It now derives scope from canonical repository files and the generated sitemap, including:

- Revision 2021 department pages and lesson/note paths
- Revision 2026 department pages and dedicated lesson/note paths
- Portal, legal, AI, quiz and tool pages
- Indexed PDF resources
- Metadata, canonical URL, H1, duplicate ID, skip-link and local-reference checks
- Endpoint, mock-score integrity, redirect and inline-script regression checks

CI also performs JavaScript syntax validation, accidental-secret scanning and post-deployment live commit/signature checks.

The generated report records its Git commit and generation time. A report whose commit does not match the inspected revision is stale and must not be presented as current.
