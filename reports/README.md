# Reports

Generated reports and analytics data for the POLY PMNA platform.

## Contents

This directory contains periodically generated reports including:

| Type | Description |
|------|-------------|
| Usage analytics | Site traffic, page views, and user engagement metrics |
| Content reports | Lesson completion rates, note download counts |
| Quiz analytics | Daily quiz participation, score distributions, leaderboards |
| Maintenance logs | Scheduled maintenance window execution records |

## Generation

Reports are generated by the automation scripts in the `/automation/` directory. They are not displayed on the public site and are intended for the site administrator.

## Privacy

Reports contain aggregated data only. No personally identifiable information is stored in this directory.
