# POLY PMNA Revision 2026 — Complete Subject Handbook Standard V2

This standard replaces brief notebook-style lesson generation for Revision 2026 courses.

## Core rule

Every official syllabus row must map to a visible, detailed handbook section. A lesson is rejected when it merely restates headings, uses generic filler, omits an official syllabus point, lacks module navigation, lacks answers, or prints only the currently selected panel.

## Required structure

1. Course cover and verified official course facts.
2. Course outcomes, prerequisites, teaching and examination schemes.
3. A syllabus-to-handbook coverage matrix.
4. Four clearly labelled module panels matching the official syllabus.
5. Detailed chapters for every official subtopic and practical outcome.
6. Subject-specific diagrams, flowcharts, waveforms, tables and controlled animations.
7. Formula/rule bank, worked examples, common mistakes and verification methods.
8. Malayalam concept support while retaining English technical terms.
9. Practical/record centre when applicable.
10. Module question banks with answers and model points.
11. Complete official self-learning schedule.
12. Course-specific assessment readiness, resources, equipment and software.
13. Official syllabus coverage checklist.
14. Full-document print/PDF mode and autoPrintNotes fallback.

## Every chapter must contain

- mapped learning outcome and syllabus scope;
- definitions, terminology, symbols and units;
- detailed concept, principle, construction, working or procedure;
- labelled visual explanation;
- derivation or formula where prescribed;
- applied example, solved numerical or stepwise task;
- applications and engineering relevance;
- limitations, safety points, common errors and troubleshooting;
- Malayalam concept explanation;
- mastery check and exam-ready answer frame.

## Repository paths

- HTML: `revision-2026-content/lessons/lessons-[COURSE_CODE].html`
- PDF: `revision-2026-content/notes/downloadable-notes-[COURSE_CODE].pdf`

Never place Revision 2026 files in Revision 2021 folders and never add an `_REV2026` suffix to these filenames.

## Validation

Validate semantic HTML, four module panels, all syllabus rows, Malayalam presence, sufficient chapter depth, inline JavaScript, mobile responsiveness, accessibility, complete print output, PDF fallback, subject-card availability and live deployment before reporting completion.
