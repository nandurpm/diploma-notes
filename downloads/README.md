# Downloads

Standalone downloadable resources for students.

## Contents

This directory contains files that are directly downloadable from the site without being embedded in lesson pages or notes sections.

## File Types

| Type | Description |
|------|-------------|
| PDF documents | Standalone reference documents, guides, and supplementary materials |
| Archive files | Compressed bundles of multiple related resources |

## Access

Files in this directory are linked directly from the site's tools and resources pages. They are not automatically indexed by the site assistant.
